# Source coverage and unfamiliar models

Use the same source-driven workflow for every model name. The preset catalog is a construction palette, not an import allowlist. A model never needs to be called Transformer, Encoder, Decoder, PatchTST or a preset name to be displayed or edited.

Parse source without importing or executing it. Identify the actual local Module entry and source root; retain source spans, constructor literals, instance sharing, ports and source/IR digests. Direct authored helper methods, module-valued constructor arguments and local module variables can be recovered. Bounded return-expression factories using ModuleList, Sequential and exact copy.deepcopy contracts can preserve independent copies. A narrowly verified standard parameter-initialization helper preserves topology. Decorated/replaced helpers, side effects, unsupported inheritance, dynamic loops/conditions, ambiguous shapes and unresolved external calls do not acquire guessed semantics.

Display an unresolved region as a source-backed opaque object. Keep its source expression and input dependencies visible. An opaque object can be renamed for display, styled, moved, connected through movable visual ports, saved, reopened, undone and exported without lowering it to a registered preset or regenerating Python. Recursively expand proven composites in the independent editing frontier; preserve hidden node edits and return to the compact source view through the original CanvasDocument history. A presentation change must not create a new managed model or silently discard a structural change.

For a config-driven branch with missing values, show the conditional boundary first and allow expansion into both authored paths. Source inspection follows local module constructors, guarded initializer assignments, attribute aliases and symbolic ModuleList element templates. A missing repeat count does not hide the available element definition. These nodes carry `sourceStructure: true`, source spans and expressions; they have no tensor ports, runtime instance identities or inferred repetitions. Keep their English source names. The original conditional boundary retains its conservative input/output bindings. Inspection is bounded to 480 added nodes and 12 levels within the total 1200-node limit; prioritize branch/module structure over expression leaves and expose truncation in metadata and diagnostics. This is available source structure, not a claim that both paths execute.

Source inspection includes separately recorded `sourceRelations` for syntactic value dependencies: nested call arguments, local assignment/alias passing, branch joins and the registered Sequential contract. Draw these as arrowed dotted source dependencies in both view and editor, with an execution-path-unresolved legend. Never chain adjacent statements, mutually exclusive branches or ModuleList members merely by their display/construction order. Local call interfaces bind positional/keyword parameters and structured returns to source dependencies, including nested composites, helper methods and Sequential. Boundary dependencies join proven external producers/consumers to the inspected entry/exit cards; their evidence names the original conditional boundaries and conservative edge IDs, without creating tensor IDs or ports. Distinct tuple/dictionary slots and variable assignments retain distinct dependencies. These relations do not establish runtime topology or shapes. Project arrows through collapsed containers and restore exact canonical evidence on expansion; movement reroutes display anchors without changing source facts. When an expanded boundary has complete visible source coverage, show the continuous source arrows in place of its redundant container strokes while retaining all original bindings in scene/draft data and export metadata. Incomplete recovery, missing children or truncation retain conservative boundary strokes. Collapsing the boundary restores those strokes. Detail exports include only source relations inside the selected subtree. Analysis retains at most 1440 source relations and reports truncation.

Ask for configuration only when selecting the real branch, verifying shapes or preparing a semantic edit depends on it. Do not infer configs, tensor dimensions, optional-mask behavior or training mode from the model name. Existing saved canvases bind immutable analysis facts; a new parser cannot retroactively add children to an old IR. Analyze into a fresh document and preserve the old document/history rather than silently replacing its facts. Additional source lowering requires positive and negative fixtures, stable identity/sharing checks, no-execution evidence and an import→edit→view→save→reopen→export check using names absent from the preset catalog.

Parameters, node insertion/removal and tensor rewiring are semantic changes. Use supported reviewed source intents or a separately validated generated draft. Source inspection nodes are not registered construction presets and cannot be lowered through the graph generator. If an opaque operator lacks a generation contract, preserve the original source and edited canvas, identify the exact unsupported expression, and retain structural work as a proposal. Successful visual editing does not establish arbitrary Python roundtrip generation or execution.

Source-authoring import/frontier/validate/generate and draft persistence have a 16 MB serialized-data budget, independently of the 80-file/2 MB source, 1200-node and 3600-edge analysis contracts. Canvas persistence keeps its 4 MB budget and shares immutable architecture facts between undo snapshots; reads reconstruct the exact original snapshots before validation. Browser local-storage quotas are host-dependent; use explicit server save/reopen for large drafts rather than assuming browser recovery succeeded.

Source provenance binds JSON number values consistently across Python and browser serialization: `0.0` and `0` represent the same JSON number. Actual value changes, boolean/string substitutions, source bytes and source/IR identities remain guarded; historical Python-only receipts remain readable with their original bytes.
