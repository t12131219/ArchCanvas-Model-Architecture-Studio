# Preview snapshot synchronization performance

The recursive preview owns its geometry, routing, transactions, and undo. The parent Studio mirrors the finished visual state into its source-bound document for the existing panels and authoring handoff.

Previously every incoming snapshot was replayed as formal `expand` operations. The formal expansion engine repeatedly built and routed a second scene while materializing children and displacing neighbors. React then built the formal scene again and rendered SVG markup which was not mounted in the preview. This could block the shared UI thread after the iframe had completed its own expansion.

`projectPreviewHistory` now validates the document before and after an immutable projection of the preview's finished positions, expansion flags, and presentation. It preserves the exact source architecture and hidden frontier memories. The preview remains responsible for layout and its undo transaction. Changed parent snapshots produce one history entry; repeated tool, selection, or busy snapshots leave document identity and revision untouched. Formal source editing retains its guarded source parser and existing visual-operation contract.

The parent builds a formal scene only for explicitly requested legacy recovery, automatic-port, and move inspection tools. Normal preview expansion and native annotation selection no longer run the hidden formal renderer. Note conflict checks and “move below” use the actual visible leaf bodies, native wrapped-text bounds, and legend card; expanded frames retain their empty annotation space. Repeating placement excludes the selected note and creates no displacement. Left hierarchy and object-panel operations containing expansion, including mixed expansion/style transactions, go directly to the preview and await one authoritative snapshot. Source-byte checks are cached by the immutable source/architecture pair; mapping coverage is cached by source-evidence identity, independently of geometry.

Initial opaque panel documents now use direct validated document construction from the preview’s measured positions and source corpus. They do not call the formal scene constructor to create a layout which the preview would immediately replace. Parent/child and port indexes use linear passes. Hidden expansion memories come from recursive open/folded state, including branches temporarily hidden by a collapsed ancestor. A busy snapshot updates toolbar state while retaining document/source ownership; source replies must match both preview and load generations, so A→B→A model switches cannot revive an old asynchronous reply.

## CPU-only measurement

Run:

```bash
node --experimental-strip-types studio/scripts/benchmark-preview-projection.ts
```

The earlier recorded Transformer fixture has 83 nodes and 85 edges. The probe projects its overview into full detail. The retained legacy replay path took 12,567 ms in one recorded sample, including 12,271 ms in formal operation replay and 291 ms in the additional hidden scene. The new validated snapshot projection took 0.39–1.08 ms across 20 samples; unchanged snapshots took 0.29–0.59 ms. The receipt is `docs/evidence/preview-expansion-20261014/parent-projection.json` and includes the earlier source hashes. It remains an attributed comparison for those bytes; it is not the final generalized runtime receipt.

The final parent-only probe, `node --experimental-strip-types studio/scripts/benchmark-preview-generalization.ts`, covers 13 recorded/synthetic fixtures with 10 samples each. Recorded families include Highway, DenseNet, UNet, VAE, GraphNet, TextCNN, two TimeMixer graph sizes (102/145 and 168/240 nodes/edges), and the source-free routing lab. Their canonical Python files are SHA256 checked and included unchanged in panel projection. Synthetic multifile cases exercise 12 and 480 nodes, recursive and plain snapshots, distinct calls sharing one instance, fork producers, and tuple slots; the 480-node cases contain 476 edges. Recorded projection samples range from 0.05–1.82 ms; 480-node samples range from 1.48–3.43 ms. Exact local coordinates, architecture identity/bytes, and no-op history stability are checked independently of timings. The current receipt is `docs/evidence/preview-generalization-20261014/parent-projection.json`, with implementation, snapshot, and source-corpus hashes.

This is a CPU synchronization comparison on recorded graph data. It excludes iframe transition, Worker routing, transport, React paint, and native event latency; browser interaction evidence measures those separately. Timing is not a test assertion or a general performance guarantee.

The final targeted parent suite passes 41 tests. It includes a fresh formal AST fixture generated by `python3 -I -B studio/scripts/generate-preview-ast-fixture.py`: three source files with repeated shared-module calls and separate return slots. The receipt checks parser paths and module hashes; top-level Python text contains a deliberate `raise` and remains unexecuted, and `torch` is not imported. Distinct source call sites map independently; repeated nested source spans which cannot map uniquely retain an opaque panel instead of declaring executable topology. The fixture receipt is `docs/evidence/preview-generalization-20261014/ast-multifile-fixture.json`.

The regression tests independently check exact preview coordinates and expansion, unchanged source identity, no-op history stability, undo/redo, ancestor movement of pinned descendants, atomic rejection of invalid presentation, evidence-cache invalidation, and delegation of hierarchy expansion without a second layout.

## Vendored engine regression

Run the preserved reference test definitions against the formal runtime with:

```bash
python -B studio/scripts/test-preview-engine-regression.py --concurrency 2
```

The temporary CommonJS harness copies only the four test definitions and a three-line graph-audit helper from the read-only reference tree. Its runtime, data and snapshots link to the formal Studio assets; the script verifies resolved module locations and hashes before and after the run. The original captured overlap fixture is remapped to its formal snapshot location. One upgrade test's hardcoded presentation version is updated from 10 to the formal runtime's current version; its source, layout, branch-memory and caption assertions remain intact. Both adaptations and original/copy test hashes are recorded. The original prototype runtime is never loaded. `--concurrency 1` allows a serial run, while `--prepare-only` records provenance and checks resolution without executing the suites. Browser latency measurements should run separately from this CPU workload.

The earlier 2026-10-14 run passed all four suites in 225.04 seconds. Node's isolated reporter counts four test files; independent source declaration counts are 44 graph-engine, 18 recursive-expansion, 3 boundary-lanes, and 5 interaction-mode cases, for 70 declarations. Runtime and fixture hashes matched the formal assets after that run. Later engine changes require their own final receipt; this parent-only probe does not rerun or certify engine routing. The receipt and log are `docs/evidence/preview-expansion-20261014/engine-regression.json` and `engine-regression.log`.
