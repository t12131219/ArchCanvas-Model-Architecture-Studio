# Studio 界面可用性与整理验证（2026-10-16）

本次修改正式项目的 Studio 与已迁入的 Summary_Merge 交互桥接层。重点是让按钮的可用状态、实际选区、预览效果和历史记录相互一致，并整理整个工作区。没有修改模型解析器、模型生成规则或 ACT 源码，也没有建立专用适配器。

## 已修复的问题

| 原问题 | 当前行为 |
| --- | --- |
| 对齐可点击但没有易用的多选方式 | 选择工具统一支持单击、Ctrl / Shift / Command 点击增减选区、空白拖动框选。没有独立“多选”按钮。 |
| 多选后拖动容易只移动一个模块 | 拖动选区成员预览整体位移，松开后提交一次有约束校验的移动，一次撤销恢复。普通点击已选成员回到单选。固定成员或非法位置会拒绝移动并说明原因。 |
| 对齐、分布的适用条件不清楚 | 同级节点至少两个可以对齐，至少三个可以分布；固定节点、跨容器选区和非法几何保留原位置。相应按钮禁用或显示即时解释。 |
| 多选时仍显示单个节点属性 | 多选显示数量、对象名称和可用操作，隐藏单个节点的属性表单。 |
| 源码导入表单挤在同一行、文件选择器意外露出 | 重排为有标签的入口和文件名、独立代码区、文件选择按钮、行内错误；单文件与工程 / JSON 分页。隐藏文件输入保持隐藏。 |
| 工具栏、顶栏和侧栏内容过密 | 工具按选择、连接、历史、排列、视图分组；案例库留在“模型”二级菜单；左右面板可收起；层级支持搜索并保留祖先链。 |
| 属性、检查信息和帮助长篇常驻 | 排列、端口、模型事实、分析边界和编辑器搭建说明按需展开；常用属性保持直接可见。 |
| 菜单打开后难关闭、互相遮挡 | 临时菜单互斥，支持外部点击、Escape 和方向键导航；导入弹窗限制焦点并在关闭后恢复。 |
| 已保存文档重开仍提示未保存 | 以文档身份及实际预览图摘要记录保存状态，区别于“相对源码基线存在视觉编辑”；缓存失效不阻止正常保存。 |
| 添加说明后出现“没有匹配的说明文字” | 聚焦请求与创建请求按相同异步次序发送，避免聚焦先于创建。 |
| 同一函数多个输入在层级树中无法选择 | 用源码参数证据与正式输入端口名称进行通用匹配，不依赖显示名；ACT 的 image / qpos 层级树多选已通过。 |
| 原有草稿展示映射失败后难以返回 | 错误说明草稿保留，并提供“查看原始视图，保留草稿”直接入口。 |

选择菜单直接附在箭头选择工具旁，提供选择同级、全部可见模块、清空选区。Ctrl+A、Escape 和中键平移保持相应行为。框选只取完全包含的可见模块，不把展开容器和内部节点重复加入选区，也不选布线汇流点。视觉连接仍是视觉草稿。

## Tavotto 参考方式

参考 `Source_Code_Project/Tavotto/web` 的工具栏分组、属性分节、折叠菜单、表单层次和低密度界面组织方式，并按本项目的递归画布、来源证据和模型编辑流程重新实现。没有复制 Tavotto 的组件代码、运行时或资源；不依赖该参考项目才能构建或使用 Studio。

## 真实界面验证

在 `http://127.0.0.1:8897/` 使用实际页面、鼠标、键盘及文件选择器验证。用于破坏性编辑的对象是临时导入的 `UIAuditModel`（两个 Linear 和一个 ReLU），没有执行 PyTorch 模型。

| 功能 | 实测结果 |
| --- | --- |
| Python 导入 | 无效源码在弹窗内显示错误；有效源码生成 6 个图节点、4 条可见连接，无待解析区域。 |
| 选择 / 多选 | 画布和层级树共用选区；Ctrl、Shift 点击和原生鼠标框选成功；三个计算模块选中后对齐 / 分布可用。 |
| 左对齐实际效果 | 先把 first 向右移动 24，first 的 x=170，last 的 x=146；左对齐后均为 146，y 保持 260 / 508；撤销回到 170，重做回到 146。使用实际 `.node-hit` 几何核对。 |
| 不合法排列 | 同列节点强制顶部对齐会碰撞，显示原因并保留原位置；无选区时排列禁用。 |
| 选区整体移动 | 实际鼠标拖动三个模块，显示整体移动成功，一次撤销恢复。 |
| 固定 / 解锁 | 节点的实际固定状态更新，可再解锁。 |
| 连接 / 折点 / Apply layout | 建立 first 到 last 的视觉草稿边；重算后共 5 条边；添加实际折点；撤销临时操作后恢复 4 条原始边。 |
| 层级搜索 | 搜索 activation 保留模型祖先；无匹配时显示空状态。 |
| 面板 / 菜单 | 左右收起恢复、源码抽屉、布线抽屉、案例库二级入口可用；菜单互斥及 Escape 关闭可用。 |
| 图例 / 页面 / 说明 | 新增、改名、删除图例会更新图；黑白配色、页宽及新增说明可用，说明实际出现在预览中；新建后聚焦不再误报。 |
| 视图 / 编辑 | UIAuditModel 实际切换成功；删除已有模块后可用源码结构恢复模块和连接。ACT 成功进入编辑；其已有草稿的部分位置同步仍受下述限制。 |
| 自定义模块 | 默认 CustomBlock 静态预览成功，加入模型成功，撤销成功。 |
| 保存 / 重开 | 实际保存并重新打开文档，图恢复且显示正确保存状态。 |
| SVG | 经导出弹窗生成后，点击“下载文件”得到真实 SVG；XML 可解析，导出不包含编辑命中框。 |
| 编辑 JSON | 实际下载并通过工程弹窗重新导入，恢复 6 个节点、4 条连接及源码适配信息。 |
| 窄窗口 | 1088×768、900×720 视图模式没有页面横向溢出，工具栏换行且可用，左右侧栏可折叠；临时窗口尺寸已恢复。 |

PDF / PNG 在当前运行时未启用，界面保持禁用。本次没有把这些格式或所有模型的任意源码增删改计为验证通过；本报告验证的是界面操作与既有能力的衔接，不能替代模型语义验收。

ACT 现有编辑草稿曾展开并调整内部源码对象。把其中的某些位置同步到仍收起的预览时，缺少唯一图元绑定，仍会拒绝这次展示同步。本次没有绕过该保护，也没有把它计为完整通过；错误旁增加了直接返回原始视图的按钮，原草稿及历史继续保留。修复完整的隐藏内部位置回传需要继续完善两个图契约之间的布局映射。
