# M4：模块库可发现性与预制起点浏览

> **历史范围提示（2026-10-06）**：本页记录 BV 模块库阶段。其 15 组动作 JPEG 的独立回读为 `pixelSynchrony=failed`，部分 JPEG 比 DOM/公开状态滞后一步，不能认证切换、搜索、清空或添加后的可见结果。当前构建的文字/提示与浏览器边界请从 [可读画布阶段](m4-readable-canvas.md) 开始。


2026-10-06，基于 `index-BV-fWDiR.js` / `index-QPVAzYp6.css`，左侧模块库增加两个明确的浏览入口：默认“基础模块 17”，以及“网络起点 3”。默认入口直接显示 Input、Output、Linear 和激活模块；切换到网络起点显示 MLP、CNN、残差 MLP。搜索词非空时跨两类搜索，结果栏显示两类数量；清空搜索回到当前入口。入口状态只改变库视图，不改变草稿、节点、连线、选择、历史、连接状态或相机。

实际浏览器复核覆盖：待连接状态切换仍保留；Linear/CNN 跨类搜索；未支持 Attention 搜索的解释；Identity 点击添加后撤销；最小 MLP 预制起点点击后一次撤销；Input 原生拖入后撤销；保存草稿重开后 4 节点、3 连线与静态检查保持。最终浏览器目录 [browser-attempt-1](evidence/m4-module-library-work/browser-attempt-1/manifest.json) 为 15 组 DOM/公开状态/JPEG，所有动作都在同一测试草稿上，未执行模型。

目标是降低小白用户首次寻找常用入口的成本；17 基础模块、3 透明起点和现有参数/静态检查合同没有扩增。没有添加未经正式后端契约支持的模块。仍未逐模块认证、未认证复杂图的路由美观、出版尺寸、呈现性能或真人研究任务。
