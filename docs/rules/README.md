# Local Rules Index

Repository-wide rules live in `AGENTS.md`. Add a focused rule document here only when a real
subsystem has constraints that are too detailed for the root file and are not protocol
specification. Add a local `AGENTS.md` beside that subsystem to link to the rule.

Expected future rule areas are source transactions, runtime worker isolation, desktop UI,
MCP root authority, CI/release, and third-party provenance. Do not create those rule files
until their owner and enforcement point exist.
