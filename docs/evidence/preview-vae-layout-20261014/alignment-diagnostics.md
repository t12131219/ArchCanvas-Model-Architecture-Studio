# Alignment diagnostics

These are bounded implementation diagnostics from temporary VM candidates, not final browser latency results. No Python model source was imported or executed. The runtime changed while other agents completed routing fixes; each receipt records the source bytes or a candidate hash where available.

`alignment-candidate-evaluation.json` compares five selected mixed frontiers. The center candidate retains reference centers only for children of one parent whose reference centers coincide and whose reference vertical intervals are separate. Root packing is unchanged. Manual local offsets are applied afterwards. Four models retain byte-identical registered overview/full nodes, edges, attachments and labels before routing. Six small packing/manual diagnostics passed; the public API tests below provide the product regressions.

The helper candidate retains every incoming and outgoing edge. It moves only a root leaf with no source children, where every incident edge connects to one expanded root and each edge has exactly one correctly directed gate on that root, all on the same side. The helper must currently lie on the opposite side. Source-template sibling gaps are retained with a minimum of 112. Root envelopes, including labels and final manual root offsets, must remain separate. Exact registered views bypass this mixed layout rule.

The center-plus-helper candidates shortened VAE routes substantially but increased some deep-view crossings. `alignment-helper-crossings.json` records this tradeoff. Crossing counts use strict segment intersections between different wire identities; they do not certify a crossing-free drawing.

`blocker-lane-probe.json` evaluates 24 candidates against a completed deep VAE frontier in about 27 ms. Both original right-side producer and consumer ports are permitted. A right lane around the intervening sampling frame at its boundary plus 12 or 22 leaves the two values 10 units apart. The whole-edge source, gate, stroke, label and wire checks pass. This probe demonstrates a general local blocker-lane construction; the recorded coordinates are evidence, not model-specific product rules.

`blocker-local-quality.json` applies those two proven local candidates to the completed temporary graph and runs the full view validator. Source and layout checks pass, with no invalid edges, lane contacts or constrained routes. Total length falls from 14900.66 to 13938.24, bends from 68 to 58, unrelated strict crossings from 18 to 13, and long parallel segment pairs less than 3 units apart from eight to two. The older layout baseline has 12 strict crossings; this experiment alone does not establish non-regression for every quality metric.

`alignment-regression.json` records eight public `F.build`/`F.toggle` regressions in `studio/tests/previewLayoutAlignment.test.ts`. They cover reference center groups and distinct columns, manual offsets and fold/reopen, helper placement in all four directions with incoming shape evidence, missing/multiple gates and contained leaves, final manual root collisions, and registered overview/full geometry. These tests do not call private packing functions.
