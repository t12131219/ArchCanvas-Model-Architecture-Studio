# Independent routing refinement evidence

This is AI engineering verification. It does not count as a real researcher task, physical publication review, a full current browser visual matrix or native presented-frame performance acceptance. No user model is imported or executed, no dependencies are installed, and historical raw captures/seals are not modified.

The oracle in `oracle.ts` imports types only. It has its own strict absolute SVG path parser, collinear compaction, strict-interior perpendicular intersection, merged collinear interval length, owner/ancestor body and header analysis, canonical-port anchoring, endpoint directions and U-turn detection. It never imports the product router, path parser, intersection or scoring helpers. `controls.ts` rejects 15 deliberate corruptions. Thirteen controls retain coherent canonical endpoint geometry, including a target body + port + route displacement and a whole-figure translation; tensor tampering cannot conceal geometrical crossings. The subpixel control rejects a 0.03-unit anchor drift. Pure floating-point representation differences below 0.000001 units are tolerated; serialized nodes/ports and semantic facts remain exact.

`before/` freezes public API output from the complete 13-file CIVB core archive in `docs/evidence/before-m4-routing-refinement/files/studio/src/core`. The source-bound input CanvasDocuments come from their declared, hash-bound historical matrix captures. `after/` contains actual final public API output, with unchanged source-file hashes before and after capture. There are 73 source-bound scenes: 9 full frontiers, 28 expanded detail pages and 36 moves (left/right/up/down for one recorded visible object in each frontier). Each move is checked against the public move preview, guarded history commit, SVG, exact layout/frontier snapshot undo and redo. The source architecture, pins and input files remain unchanged. The public test also verifies pinned objects do not move. Scene revision counters are explicitly excluded only when comparing undo/redo to the earlier scene.

The final `audit-after.json` passes 73/73 and `public-tests-final-with-source-binding.txt` passes 13/13 with no skips. The earlier `public-tests-final.txt` is also retained. The final public test adds hash binding of every source-bound CanvasDocument and protection of ancestor movement when its descendant is pinned. `before/fixtures.json` and `after/fixtures.json` add three manually declared graph fixtures through public `createDocument` / `buildScene`: different tensors, a shared tensor trunk, and different tensors sharing a fixed departure port. These are geometry contract fixtures rather than framework/runtime observations. Shared tensor trunk overlap remains 119 units and its path bytes stay exact. The two different-tensor cases reduce overlap length from 300 to 8 units and from 119 to 6 units respectively, while both retain one overlap pair. They prove the boundary as well as the improvement.

For the final full Transformer scenes, the independently measured values are:

| Frontier | Distinct-tensor crossing pairs / pair-points | Distinct-tensor overlap pairs | Disjoint-owner overlap pairs | Total bends | Total route length |
| --- | --- | --- | --- | --- | --- |
| L0 | 1 / 1 → 1 / 1 | 7 → 7 | 3 → 3 | 24 → 20 | 2,748.5 → 2,494.9 |
| L1 | 23 / 24 → 20 / 21 | 8 → 7 | 5 → 4 | 76 → 72 | 9,428.78 → 8,985.98 |
| L2 | 22 / 25 → 22 / 25 | 25 → 19 | 19 → 13 | 116 → 116 | 20,255.28 → 20,303.28 |
| L3 | 20 / 23 → 20 / 23 | 25 → 19 | 19 → 13 | 124 → 124 | 25,605.96 → 25,653.96 |

A crossing pair is an unordered edge pair with one or more strict-interior perpendicular crossings; pair-points count unique locations within each edge pair. Turns or segment endpoints are not strict crossings. Overlap pairs contain positive collinear overlap, and reported lengths merge shared intervals on the same lane per pair. Different tensors and disjoint projected endpoint owners are separate filters; repeated/shared tensor trunks are measured separately.

Thirty-four of the 73 source-bound scenes change routes and improve conflict/overlap measurements. No final scene increases crossing pairs, crossing pair-points or overlap pairs in either protected filter, no final scene introduces a body/header penetration or U-turn, and no scene increases total bends. Twelve scenes increase total route length by 16–48 units as a tradeoff for less overlap; L2/L3 full scenes each add 48 units. Overlap lengths never increase in either filter. Residual crossings and overlaps remain; there is no claim of a crossing-free, globally optimal or aesthetically certified layout. Five simple full MLP/CNN frontiers retain exact route bytes.

`after-initial/` and `audit-after-initial.json` retain the rejected first iteration (33/73 passed, 40 first failures were path anchor quantization). `after-budget384/` and its passing audit retain the second iteration. These are historical intermediate results; the final binding is `after/`. The oracle initially used exact numeric equality and then adopted the stated 0.000001 tolerance for binary floating-point representations, while its 0.03-drift negative control still rejects the product precision defect.

The actual browser representative is separately parsed from public DOM SVG and real CAS store copies using the standard XML parser in `parse_browser_svg.py`. It independently compares stored CanvasDocument, visible node XML, port XML, source facts and rendered bindings before calculating actual route geometry with `audit-browser.ts`. Publication body/header checks include the SVG divider plus its documented four-unit padded header band. The final `browser-audit.json` passes on 49 nodes, 59 edges and 106 public ports across build CIVB6v-J and CVO3JbfE. It finds exactly three changed routes (`edge:25`, `edge:29`, `edge:57`); its actual route metrics match the final L3 row above, including the remaining 20 crossing pairs / 23 pair-points and 48 extra route units. Stored document revision 7 / storage revision 1, owner/port XML, source facts and bindings stay exact. No screenshot pixel/font judgement is claimed by these field and geometry checks.

The actual service-created publication SVG, receipt and source CanvasDocument are separately audited in `actual-export-audit.json`. Their copied bytes match the live service artifacts selected by the observed browser export link; receipt digest and size bind the actual file. Standard XML parsing finds the same 49 nodes, 59 edges, 106 ports, metadata, route bytes and semantic projection as the actual reopened browser SVG. Physical preflight is independently recomputed from actual text `font-size`, line `stroke-width` and viewBox. At 180 mm width the full Transformer page is 598.61 mm tall and has minimum text 5.36 pt, below the adjustable 7 pt starting recommendation. Font family fidelity, embedding, physical publication acceptance and a user download click are not established. Later root viewport/screenshot records are outside this independent audit scope.

Reproduce the current public tests without modifying frozen evidence:

```bash
cd studio
node --experimental-strip-types --test --test-isolation=none tests/routing-readability-independent.test.ts
```

To collect a fresh independent comparison, use `capture.ts after after-newlabel`, then `audit.ts after-newlabel`. Capture/audit tools refuse to overwrite raw or prior audit files. The final manifest hashes raw before/intermediate/final output, oracle, scripts, public test and browser evidence separately.
