# Independent collapsed Repeat SVG oracle

This bounded check reads the final published SVG's direct node card rectangles, edge paths and port circles. It imports no product outline, path parser, projection, intersection, routing candidate or tensor scorer as an expected-result oracle. The router is invoked only as the system under test for independently authored path counterexamples. Rounded corners remain conservatively represented by the nominal card rectangles.

`before.json` binds the explicitly sealed **formal ChS** core under `docs/evidence/before-m4-repeat-outline/files/studio/src/core/`. `after.json` binds the current formal core. These targets never import the failed prototype, execute a model, install dependencies or rebuild the product. Both captures bind every core TypeScript file before and after, and read the same nine paper-180 baseline Canvas inputs from the immutable `browser-visual-matrix-chs-current` package. Each selected expanded container whose detail contains a collapsed Repeat is included, yielding nine frontiers plus three detail pages. Whole CanvasDocument JSON and input file bytes remain unchanged during each capture.

The sealed ChS captures contain six backplate penetrations and six buried ports (three frontier cases and their three related details). The current captures contain zero backplate penetration, buried/floating port, own endpoint-body reentry, detached path endpoint or nominal card/path clipping. Exact reported examples are CNN `(177,423)` and Transformer memory `(281,444.1)`. The six frontiers without a collapsed Repeat retain byte-identical SVG output. Canonical rendered bindings, hidden edges, detail scope, source/IR digests and source facts remain identical; front rectangle geometry, local anchors, pin state and ordinary/expanded display port geometry also remain identical.

The targeted suite has 17 tests. The same current assertions explicitly run against the sealed formal ChS target produce **7 passed / 10 failed**, exit 1. Against the current product they produce **17 passed / 0 failed**, exit 0. `sealed-ChS.json` and `current.json` bind actual direct execution, all core source hashes and test/oracle/fixture hashes before and after. The respective stdout logs retain all failures and passing assertions. No count is added across these separate runs.
