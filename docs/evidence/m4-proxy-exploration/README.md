# 三角色代理探索：当前 CVO 构建

用户要求部署3–5个子Agent，重点尝试视图四向操作、箭头排布和小白从零搭建。部署三个角色，结果均为AI工程探索，不计真实研究参与者或出版审看者。真人研究包保持五席未分配、零记录。

| 角色 | 实际方式 | 原始记录与范围 |
|---|---|---|
| 小白搭建 | 子Agent自己的8936服务与浏览器实际UI | [novice报告](novice/README.md)：拖入Input/Linear/ReLU/Output、连接、错误与参数恢复、撤销/重做、保存/重开、生成新Python与新工作副本制图；四向键移和平移。 |
| 四向操作 | 子Agent自己的8937服务与浏览器实际UI | [movement报告](movement/README.md)：四向拖动、undo、上移另redo、四向pan、缩放/fit/展开；保留上移和右移的碰撞警告。 |
| 箭头审看 | 子Agent浏览器不可用；root在8938/tab42代采，角色只读看截图 | [arrows报告](arrows/report.md)：概览/L3/100%输入与memory局部、实际服务SVG派生图。该角色曾参与路由实现，不能称独立几何oracle；几何独立oracle在另一证据目录。 |

模块库实际有17种可拖入模块、11分组，包含卷积、池化、归一化、嵌入、两路Add/Concat及常用激活；还没有Attention、LSTM或组合网络预制。它具备DL-Playground式左侧模块库与空白搭建入口，但不能声称覆盖尽量多的常用网络模块。

小白代表MLP闭环完成，发现的具体改善项仍开放：搜索未支持的Attention时没有空结果说明；按连接排版后Output可能位于当前视窗外，需要再点适合画布；形状错误是英文文字且没有突出对应节点。四向手动移动保留用户位置，上移/右移可以造成重叠，产品显示告警并可撤销恢复；并非所有方向自动得到整齐图形。复杂Transformer的长页、mask通道拥挤与短折线仍影响观感。

各代理使用独立存储，不操作8765、8916、8917或真人试用席位。不会执行生成模型来绘图，未安装依赖，未修改产品源码。浏览器环境与root不同，viewport不能合并；代理成功不等于真人任务成功，截图/静态生成不等于运行或出版认证。
