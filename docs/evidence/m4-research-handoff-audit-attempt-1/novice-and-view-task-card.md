# 从零搭建与视图操作探索卡（未执行）

这份卡补充用户要求的新手搭建、预制模块和视图操作检查，不替代技术计划 §18 的同源 Transformer 五步研究任务。使用另外独立 workspace/草稿；不要把生成新模型后的 document/source/IR 混入原五步记录或 180 秒分母。AI 使用者类型必须为 `automation`；真实使用者的身份与最终工件仍由独立人员复核。

主持人先填写当前构建 JS/CSS 名称与 SHA256、workspace、实际浏览器/viewport/DPR/字体证据，确认草稿为空。参与者只依赖可见画布与界面提示，主持人把每次提示、帮助或绕路原样记录。每项都允许失败/放弃；不以“最终有一张图”推定全部操作成功。

| 检查 | 参与者任务 | 主持人与独立复核者要保留的证据 |
|---|---|---|
| 从零建模 | 从空白草稿找到 Input、Linear、激活和 Output，拖入/添加并连成一个模型；只靠参数提示修改一个合法尺寸，再制造并修复一次不匹配。 | 空白图、每次添加/参数/连接的节点和端口身份、检查提示、实际草稿文件；记录拖入与点击是否都可发现。 |
| 模块库 | 找到基础模块与网络起点入口，搜索一个现有模块和一个未支持模块；选择一种透明起点，修改其普通节点。 | 首屏/搜索/清空/未支持说明/起点的可见截图与 DOM；记录模块清单真实数量，禁止推定每类已运行。 |
| 节点四向移动 | 对同一节点分别向右、左、上、下移动；每方向看清节点与箭头后撤销、重做，再恢复起点。 | 逐方向 before/moved/undo/redo/restored 的草稿坐标、route/public screenshot；source/端口/参数身份应保持。 |
| 相机四向移动 | 分别向右、左、上、下平移，再反向恢复；尝试 fit、放大、缩小和 100%。 | 每方向相机/viewport/public 状态及可见图；节点草稿坐标不变。记录离屏、拖动误触与滚动遮挡。 |
| 箭头审看 | 在总览与可读局部检查同源分支、多输入合并和被移动节点：看是否有不必要交叉、长外绕、连续重叠、冗余弯折、端口脱离、方向错误或关键遮挡。 | matched DOM/public/JPEG，准确对象/端口/边 ID、问题坐标、实际 route；不能把低缩放无法辨读记为通过，也不能用几何通过代替美观。 |
| 提示与低缩放 | 选择输出端口观察提示，切换小缩放、100% 与窄 viewport；测试长中文/Latin 标题和双输入端口尾部点击。 | tooltip 矩形、字体屏幕尺寸与遮挡对象；截图真实显示最终状态，截图晚一步/不一致须另记失败重采。 |
| 编辑恢复 | 删除一条连线和一个模块，查看结果提示并 undo/redo；保存刷新，确认草稿参数、位置、稳定身份与连接恢复。 | 删除前后与 history、最终保存 envelope 与重开草稿；历史是否跨刷新保留需按实际能力说明。 |
| 生成与出版 | 如果该图静态校验通过，生成受管理新源码、打开其新画布并导出；打开实际文件检查文字、连线和尺寸。 | 新 source/document/IR identity、实际导出 input/receipt/file 和打开截图；没有执行模型时明确 runtime 未运行。 |

任务结束时记录耗时、卡点、失败与帮助次数；记录者不自动认定真人通过。独立复核明确区分“实际执行且有证据”“自报”“缺证据”“失败”。一位参与者只用一种起点不认证全部 17 个模块或三个起点；四向移动样本不认证任意布局最优或全局路线最美。

配套 [exploration-template.json](exploration-template.json) 是空白记录 schema。当前 `StudyPanel` 没有草稿身份采集，这份侧车不借用其五个 checkpoint；observer v2 也不是此草稿/出版探索的完整自动采集器。
