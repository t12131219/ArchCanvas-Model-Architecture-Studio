usage: browser_visual_matrix.py [-h] {prepare,collect,verify,stamp-hashes} ...

Prepare and bind a real-browser visual gold matrix without granting human
acceptance. Studio screenshots must be captured by an operator in the actual
browser. This script checks local artifact consistency and produces a review
index; it cannot establish participant identity, image content or aesthetic
acceptance.

positional arguments:
  {prepare,collect,verify,stamp-hashes}
    stamp-hashes        Fill actual file hashes into an operator-observed
                        screen receipt; does not create observations

options:
  -h, --help            show this help message and exit
