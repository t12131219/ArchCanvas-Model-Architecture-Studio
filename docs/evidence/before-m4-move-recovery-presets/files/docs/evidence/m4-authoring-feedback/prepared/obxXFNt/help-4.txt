usage: research_trial.py [-h] {prepare,verify,assign,collect} ...

Prepare isolated, unassigned M4 trial slots and bind real local trial
artifacts. This script neither recruits people nor certifies human task
success. Collected records remain self reports pending independent review,
including automation.

positional arguments:
  {prepare,verify,assign,collect}

options:
  -h, --help            show this help message and exit
