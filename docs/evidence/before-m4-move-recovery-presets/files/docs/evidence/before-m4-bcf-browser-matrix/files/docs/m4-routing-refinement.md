此页记录历史 CVO 构建 `index-CVO3JbfE.js`，SHA256 `0516dc07309a95196c403fd822b3daf474ced88ec9c0ab7a8c0de85cfd0e26e9`。主画布、容器详情导出和模型搭建草稿共享有预算限制的批量路由。它先沿用模块/标题避障路径，再尝试分离不同 tensor 的重叠与交叉；保留端点、方向、身份、手动布局、固定对象和模型事实。

新增优化的预算为 1024 个节点、512 条路线、4096 个路线点；最多 32768 次边对检查、150000 次线段检查、60000 次障碍检查、384 个候选、每条路线 80 个候选、8 条待优化路线和 2 轮。预算只限制新增的优化工作，不限制原有布局/避障/SVG 的全部时间，也不承诺每份图都能消除冲突。
