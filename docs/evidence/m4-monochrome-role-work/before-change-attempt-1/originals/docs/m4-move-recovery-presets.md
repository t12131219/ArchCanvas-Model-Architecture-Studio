## 产品行为

自由拖动继续保留用户位置；越出父容器、侵入标题、兄弟重叠及受阻连线会给出布局提示。选中一个可见对象后，可显式“预览位置修复”，检查候选后选择应用或取消。预览不写画布，应用提交一次 VisualOperation，可一次撤销/重做；预览期间不能保存或导出。旧预览在文档或选中身份改变后失效。

规划最多检查 64 个候选，保护无关对象的位置和尺寸；包含所移对象的祖先容器可能 resize。选中对象或后代已固定、冲突发生在选中容器内部、或无法找到保持其他对象及 incident routes 的方案时，明确拒绝并保留当前文档。候选按登记的 diagnostic signature 与 severity 指标拒绝新增或加重：重叠用面积、越界用距离、受阻连线用所有所报告障碍的总侵入长度；不保证每个障碍的侵入量单独递减。它是局部位置方案，不认证所有交叉、折点、美观或全图布局均已解决。

搭建模式保留 17 种基础模块，并新增三个透明网络起点：

| 起点 | 节点/连接 | 声明输入 → 输出 |
|---|---|---|
| 最小 MLP | 5 / 4 | float32 `[1,16]` → `[1,4]` |
| 小型 CNN | 8 / 7 | float32 `[1,3,32,32]` → `[1,4]` |
| 残差 MLP | 6 / 6 | float32 `[1,16]` → `[1,16]`，主支路与原输入在 Add 的左右端口汇合 |

点击或拖入后仍是普通可编辑模块和 typed tensor connections。一次插入作为一次草稿历史操作，分配新身份并保留已有节点/连线；失败保持原草稿。CNN 的最终起点坐标为两行各四节点，两个方向均按计算顺序从左向右；只改起点坐标，不改通用排版、router 或语义合同。[坐标修正证据](evidence/m4-move-recovery-presets-work/preset-layout-implemented/attempt-1/receipt.json)的 fit 计算不等于浏览器实测缩放。

源码生成继续创建受管理的新模型副本，通过静态 source/IR 检查。输入shape/dtype是声明推导，生成源码未被导入或执行；Attention、LSTM、训练及导入模型任意结构写回仍未支持。
