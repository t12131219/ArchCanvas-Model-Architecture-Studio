## 产品变化

“按连接排版”对同一份更新后的草稿自动适合画布，范围包含节点和路线。排版只有一次历史操作，相机不进入草稿历史；128 节点宽图的 fit 不受手动缩放最低值限制。手动修改节点仍可制造碰撞，不承诺自动消除所有交叉或折点。

后端 `DraftError` 保留英文 error，增加中文结构化 diagnostics；不完整草稿的 issues 保留 code、portIds、nodeIds 等原有字段，单个缺失端口另提供可选 portId；原英文放在 technical，全局问题没有定位目标。唯一且实际存在的节点身份才可定位，参数和端口也须注册有效；重复或非法身份、全局与预算错误不猜同名节点。浏览器标记出错模块、相关字段与端口，提供定位按钮、技术详情和 Linear 输入宽度示例。部分非 DraftError/schema/意外错误仍可能没有结构化中文诊断。

模块搜索区分加载与空结果；无命中时说明中文/英文关键词、当前未支持的 Attention/LSTM/组合预制，并可清空恢复。原始数值输入拒绝空值、空数组项、非有限数及超出合同的值，未修正时保存/生成按钮和处理函数都阻止提交。Escape、字段卸载或实际有效值替换会说明无效输入已放弃。名称和坐标等无关修改不会丢掉尚未修正的数组文字。

初次缓存验证和保存/生成/重开结果按草稿快照身份接收；初次 catalog 在验证前可供错误解析。独立公共测试包含缺失旧 ID 不猜同名目标，源码审查检查了异步守卫；这不是对全部 React 竞态时序的动态证明。
