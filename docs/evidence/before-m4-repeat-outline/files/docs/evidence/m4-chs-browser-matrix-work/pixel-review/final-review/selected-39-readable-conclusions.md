# 39 个有效案例的独立证据结论

36 个基线案例和 3 个有效编辑案例的 78 张原始 JPEG 图均已实际查看。39 张最终图的主要可见字段与公开 DOM、SVG 和保存快照相符，结论限于适合画布缩放后的粗粒度字段。37 张 primer 保留导出模态框，2 张正常；primer 均不计额外成功。

原 Transformer L1 彩色 85 mm 错误 href 采集、原 CNN 编辑态隐藏展开标记采集保持排除，使用各自 recapture1 替换。后者两张失败原图也曾实际查看，单独计入全部 80 张唯一原图；第一次 Transformer L0 重复审核只计一次。

独立数值审核覆盖 817 条路线、1,634 个端点。主卡片重叠与路线穿透均为 0，所有端点通过 0.051 scene unit 的序列化容差检查；仍保留 28 次叠片穿透、997 次点接触、547 次共线重叠和 365 次严格交叉。数值是序列化线段发生次数，不是唯一像素或网络交叉数量。

25 张最终图明确观察到工作区点网格，公开 JSON 缺少网格状态，DOM 按钮无 pressed 标记，因此无法确认状态相等或原因。物理 85/180 mm 可读性、小字、箭头、字形与实际描边边界均未认证。精确注释文字来自源数据；Transformer 两个 tspan 以空格连接与保存句子一致，无分隔 DOM 拼接不能作为像素丢词证据。

新 CNN 主图和图例集中在页面顶部，blocks→pool 距离为 38 scene units。注释仍位于 y=2529，页面为 180×781.71 mm，因此保留大量注释前空白；旧失败图 1,614 的节点间距不沿用到新图。

432 个去重原始及上下文输入、汇总时 176 个报告和辅助源码重哈希不变。独立结构汇总单列 353 个结构输入、39 份报告及 14 份补充。发现读取早于部分绑定；哈希不证明首次采集不可变或截图同步。性能试验数为 0，运行时语义、原生字体硬件锁定和人工验收均不在结论内。

最小叠片候选修正是统一计算折叠 Repeat 的有效外轮廓，把显示端口圆和路线端点共同投影至该轮廓，保留 canonical 绑定。两示例端点当前位于叠片内部，仅调整后续折点不能消除穿透。L3 不同 tensor 的 19 对正长度重叠优先，其次 20 对严格交叉；候选仍需独立检查和实际像素复核。产品未在本审核中修改。
