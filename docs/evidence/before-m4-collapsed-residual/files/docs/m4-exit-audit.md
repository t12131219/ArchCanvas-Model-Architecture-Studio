## 研究任务能否执行与复核

五步所需控件已具备：真实示例树展开、显示名/颜色/图例/annotation 编辑、拖动/pin、undo/redo、服务端保存与刷新恢复、同源 SVG/PDF 导出。当前没有一份完成全部五步的研究使用者记录；部分浏览器冒烟和不同历史工件不能拼成一个真人的完成记录。
