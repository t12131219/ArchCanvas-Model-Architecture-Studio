正式后端 catalog 源码共有 **17 种模块、11 类、34 个参数字段、12 个带参数的模块**。本审查用 Python 标准库 AST 读取 catalog 定义，并与 `draftParameterHelp.ts` 的声明键逐项比较：34 个字段均有中文帮助；这是源码库存核对，不是逐模块功能测试。

| 能力 | 当前登记的模块 |

| 输入/输出 | Input、Output |

## 小白仍会遇到的主要缺口

1. **基础模块不易在首屏发现。** 两张实际截图中，三张网络起点占用了左侧大部分可滚动区域。较高的 clear overview 也仅在底部露出 Input 卡片，Output、Linear 与激活入口需要继续滚动或预先知道搜索词。顶部显示“常用模块 17”，但屏幕主要展示的是三个完整网络。新手选择逐层搭建时容易混淆两种入口。
2. **选择参数后，检查详情容易落到折叠之外。** Linear 的完整帮助使右侧检查卡片位于下方；Conv2d、MaxPool2d 等字段更多，源码结构同样把检查区域放在参数与坐标后面。这是 UI 排序推断，尚未逐模块实际浏览验证。工具栏检查按钮可见，但“还有 N 项，右侧定位”的后续操作仍可增加明确入口。
3. **总览与局部阅读切换仍有成本。** 此简单四节点链也只有 58% 总览；基础节点名、类型、端口和声明形状偏小。长网络、分支与 preset 的整体阅读/拖动还需要单独的视图操作与像素检查，不能用这两张平直链截图盖章。
4. **17 种模块覆盖的是有界静态 DAG。** Add 固定两输入且不广播，Concat 固定两输入；Embedding 的实际索引合法性不由静态形状证明。多头注意力、LSTM 等不是当前 authored subset。已有库足以作为 MLP、小型 CNN、残差与部分嵌入拼装的起点，不能当作通用深度学习可视化训练平台。

## 最有价值的下一项有界实施

优先改善 **左侧模块库浏览**：增加明确的“基础模块 / 网络起点”切换；基础模块视图让 Input、Output、Linear 与激活入口在常见桌面首屏可达，并提供类别跳转或紧凑类别展示。网络起点继续显示输入/输出声明与“添加独立网络”的含义。搜索仍能检索两类并明确结果类别，所有卡片保留原有点击、拖入、稳定 kind 与普通草稿编辑行为。

该变化只需前端组织已有 catalog，不引入新生成、验证或执行语义。后续实际浏览器验证应覆盖：空白开始、两类切换、中文/英文搜索及空结果、点击与拖入、Input→Linear→激活→Output 完全视图连接、检查及错误定位、撤销和重开、既有三个 preset 插入。图与 DOM 都应核对，不只确认按钮存在；AI 完成仍不计真人。

模块扩展应从真实模型任务选取。正式后端当前明确列出未支持的 Sigmoid、Tanh、Conv1d、AvgPool2d、BatchNorm1d、MultiheadAttention、LSTM。每个新增 kind 都需要参数/端口、声明张量规则、生成源码和独立静态 round-trip 契约后才能成为可拖卡片。Sigmoid 对二分类输出、Conv1d 对序列或时序任务有具体价值；本审查未获得任务证据来确定扩展顺序，故不建议按数量添加。此次未新增任何模块或 preset。

当前未逐模块认证；这两帧也不是新手从零搭建的最终 CW 全流程、所有视图操作、物理出版或真实呈现性能验收。原有 M4 开放门槛继续保留。
