# 当前 au3 浏览器复验

本目录是主任务在真实 CUA browser2/tab54、`http://127.0.0.1:8987/` 收集的 AI 观察。当前资产为 `index-au3IB_0Q.js` / `index-B6WbMowt.css`；[报告](report.json)绑定公开 DOM、SVG、截图、实际保存副本与服务生命周期。它不计真人，不是新完整矩阵或出版认证。

L3 的公开交互 SVG、真实 SVG/PDF UUID 和保存的 Canvas/source/IR 已在[独立只读审查](../acceptance/browser-source-readback-attempt-1/README.md)核对。`l3-export-preview.svg`误采成211字节关闭图标，保留并排除。14%全景与仅顶部的实际导出截图不能证明最终出版尺寸清晰。

端口文字命中分别通过 role click 与原生文字中心 click 建立 Input→Linear；撤销/重做按两次不同的历史编辑（名称、连接）逐项观察。后续从零构建 Input→Linear→ReLU→Output，按连接排版，保存并重开4模块/3连接草稿，静态审看新 Python，再实际创建独立工作副本、打开并保存论文图。另见[搭建独立回读](../acceptance/authored-browser-readback-attempt-1/README.md)。没有执行模型或训练，没有改写原有模型源码；这不认证 imported Canvas 的 alias 保存/刷新矩阵。

首次快速批量连端口后的 `from-zero-complete.*` 实际只有1连接，不能当完成证明；观察每次选择提示后分别连接才达3连接，原因未确定。最终草稿用 `from-zero-arranged.*` 与 `from-zero-reopened.*`，生成论文图用 `from-zero-generated-*`。`getAttribute(outerHTML)` 返回 null 和先前 fs/promises 的 mkdirSync 误用是采集错误，未冒称产品失败。所有这些原件均保留。

17模块逐个添加、3预制起点、原生拖入与MLP四向移动的47份 AI 工件属于[旧 BG 试用](../browser-ai-only/report.json)。当前版本复验范围更窄，不把旧版观察提升为 au3 完整四向矩阵。子 Agent 的 fresh CUA 不可用记录也保留；它与主任务当前成功是两个独立的事实。
