## 发现及优先级

1. **P2，按连接排版明显降低 CNN 可读性。** 拖入小型 CNN 后是两行 8 模块/7 连接，适合视图 85%，完整名称可读（09）。点击“按连接排版”后变成单行 40%，多数名称截断，`AdaptiveAvgPool2d` 也被缩为 `AdaptiveAvg…`（10）。连线没有穿框，但操作使阅读更困难。复现只需空白 → 小型 CNN → 按连接排版。建议视口感知的纯链折行；这是实际 UI 体验问题，不是参数或生成错误。撤销恢复位置但保留 40% 相机；再点“适合画布”可恢复 85%。
2. **P2，预设中含参数的显示名会过时。** CNN 卷积 `out_channels` 8→10 后仍显示“卷积 3→8”；检查正确报告分类头的末维 10 与 `in_features=8` 不匹配（47–48）。把分类头 `in_features` 改为 10 后检查通过，声明张量清楚显示 `[1,10,…]`，别名仍是“卷积 3→8”和“分类头 8→4”（49–50）。这是可编辑显示名的旧数值给小白造成事实误导。建议预设使用“卷积”“分类头”等角色名，或明确解释此处仅为别名。
3. **P3，残差首屏 53% 的名称和端口偏小。** 隐藏层和投影层含数值名称截断，但右侧选中属性和端口 tooltip 能看到完整信息（18–24、28）。没有认定为结构失败；没有真人可读性结论。

- 从卡片原生拖入 CNN 到空白画布，形成 8 节点/7 连接；静态检查通过，并保存独立草稿（08–16）。

## 17 类参数对小白的可理解性

以下参数是从 UI 实际属性面板读到，完整中文帮助及默认值见 `module-parameter-inventory.json`。所有模块均有显示名称和 X/Y；下表只列语义参数。对“足够”的评价是 AI 模拟判断，不是实测学习效果。

| 可见类型/中文名 | 可编辑参数 | 评价及边界 |
|---|---|---|
| Input / 输入 | shape、dtype | 解释批次/通道/H/W、逗号格式、1–8 维、静态声明，够用 |
| Output / 输出 | 无 | 连接结果，够用；多个命名输出只是库提示，本次未建立 |
| Linear / 全连接 | in_features、out_features、bias | 末维匹配与例子清楚，实际纠错成功 |
| ReLU / ReLU 激活 | 无 | 逐元素负数置零、保持形状说明够用 |
| GELU / GELU 激活 | approximate: none/tanh | 近似开关与浮点边界可见；未验证网络或数值 |
| SiLU / SiLU 激活 | 无 | 逐元素和形状说明够用；不要求公式 |
| Identity / 恒等映射 | 无 | 输入原样传递，够用 |
| Dropout / 随机失活 | p | 0–1、训练/评估区别、缩放说明清楚 |
| Flatten / 展平 | start_dim、end_dim | 0 起算、负轴、一维要改 start_dim=0，有具体例子 |
| Conv2d / 二维卷积 | in_channels、out_channels、kernel_size、stride、padding、dilation、groups、bias | 每项中文解释详尽，通道关系明确；面板较长需滚动，实际配置/修复成功 |
| MaxPool2d / 二维最大池化 | kernel_size、stride、padding、dilation、ceil_mode | 最大值、负无穷填充、约束、ceil_mode说明详尽；本次未改单项 |
| AdaptiveAvgPool2d / 自适应平均池化 | output_size | `[1,1]` 与空间维说明清楚 |
| BatchNorm2d / 二维批归一化 | num_features、eps、momentum、affine、track_running_stats | NCHW、每通道元素≥2、统计/优化器momentum区别明确；不是已运行训练验证 |
| LayerNorm / 层归一化 | normalized_shape、eps、elementwise_affine | 末尾维匹配例子和训练/评估说明足够 |
| Embedding / 词嵌入 | num_embeddings、embedding_dim | int64 输入、输出增加维、实际索引范围不能静态证明明确 |
| Add / 张量相加 | 无；left/right 两输入 | 完全相同形状/类型规则清楚；实际断连/接回/检查成功 |
| Concat / 张量拼接 | dim；a/b 两输入 | 固定两个输入、负轴、其余维一致明确；未搭建完整Concat网络 |
