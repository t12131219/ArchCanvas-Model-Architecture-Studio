# M4 authoring interaction：独立视觉审计

本轮确认了简单链路和输出说明的改善，但不构成全部视觉验收通过。审看者未操作浏览器、运行模型或修改产品，真人参与者仍为0。Root 的原生操作声明是对实际工具调用的回溯记录，不是同步输入遥测。

已亲看全部14张冻结 JPEG，另看了5张从原始 JPEG 裁切放大的局部图，以及1张旧纵向草图，共20张图。165个最终原始文件与 root manifest 一致；69份公开状态只读抽取了实际 SVG 路径和已记录 DOM 命中点。10对截图前后公开状态除时间戳外完全一致，但这种一致不能覆盖截图像素里的差异。

## 可以确认的改善

- 手动摆放的四节点纵向链，在81%画布图中有3条直线，箭头进入顶部输入圆点，输出文字在主线左侧、输入文字在右侧。旧保留草图的每条边有4个可见弯折，当前实际路径分别是 `M138170 V224`、`M138324 V378`、`M138478 V532`，可见弯折和严格内部交叉都为0。纵向位置来自实际摆放，不能归因于当前 Arrange。
- 实际点击“按连接排版”后的横向四链，在80%截图中有3条直线和完整节点标签；公开路径的可见弯折、严格内部交叉和正长度共线重叠均为0。
- 初始标签点击、圆点拖连、键盘第三连接的公开状态依次显示0→1→2→3条边，节点 transform 始终与连接前一致。Root 声明提供了标签点击坐标、拖连和键盘动作；它们只支持这些具体尝试，不证明计划中所有标签/圆点组合、目标边界或每种缩放都已验证。
- 可见状态中的标签、圆点、端口组和 hit 矩形中心，记录了对应节点/端口的 `elementFromPoint()` 结果。它们支持这些采样点的 DOM 命中；实际连边身份、数据形状、保存和生成另由独立契约审计核对。空身份、视口外点与仅有 DOM 命中不能计为原生成功。
- 重开保存的纵向草图仍显示4个节点、3条直线。新建 managed 论文图的清晰补图包含完整四叶链，输出说明是 `model output`。旧 managed 文档的实际元数据前后保持源事实、节点绑定和连线绑定一致，显示说明从内部返回键改为可读文字。
- MLP64%图包含5模块4条直线；CNN85%图包含8模块7连接；残差53%图包含6模块6连接。左侧显示17个模块和3个网络起点。这些是本轮三个具体图和界面的事实，不能推成全模块执行认证。

## 仍未通过或不能认证的部分

- **Concat 输入附近存在交叉。** Add 输出到 Concat.a 的横段，与 InputA 分支到 Concat.b 的竖段在场景坐标 `(614,220)` 严格相交，距 a 输入圆点6个场景单位。原生实际73%截图放大后可见两条线在箭头前形成深色结点。五条边的弯折数为 `[2,2,2,2,0]`。另一段 InputA 共用的62单位起始线属于同源分支，应与不同输入线的交叉分开描述；本轮不判定交叉是否拓扑必需，但合并视图的连线美观不能通过。
- **多个输入目标在缩放图中很小。** 残差53%图的左右输入圆点中心距约6.36px，hit 矩形高度也约6.36px，标签约6px。中心命中正确不能证明对初学者足够易点、易分辨。Merge 的新公开状态确实采了100%几何，但其名为 `merge-complete-100.jpg` 的实际画面仍显示73%；不能拿这张图认证100%像素。
- **截图名与公开状态不能替代实际像素。** `merge-complete-fit.jpg` 实际只有4条连接，Output未连，而前后公开状态已经是5条；`merge-complete-100.jpg` 有5条连接但实际73%；`managed-new-final.jpg` 实际是导出弹窗与模糊背景，不能计作清晰全图。清晰论文图以 `managed-new-clear-supplement.jpg` 为准。
- **起点提示画面未证实。** `vertical-100-pending.jpg` 有100%局部端口和蓝色焦点框，但底部原始像素仍是通用搭建说明，前后公开状态却是“连接起点已选中”。放大原图底部确认了差异；不能以 DOM pressed 状态覆盖画面，也不推断产品、截图或合成器中的具体原因。Escape后 pressed已清除，但保存的公开 footer仍留起点提示。这不是完整的持指取消认证。
- **四方向平移只有公开几何证据。** 声明和公开状态涵盖右、左、上及超时后的下移重试，节点位置保持不变；首个下移超时和部分15px移动被保留。14张冻结图没有四方向平移的对应清晰画面，部分端口还在视口外，不能确认四方向画面全部整齐或平移后所有目标仍可点击。
- CNN仍有一条跨两排的4弯长折返；残差有2弯主输入偏移和4弯跳连。没有观察到这些图的严格内部交叉，不等于证明每条路径最短、所有弯折必要或最终出版排版最优。

## 证据边界

初版观察脚本对单个 `svg` 字段及边路径非空的假设失败，原脚本和诊断保留。最终脚本读取实际 SVG 路径，并能识别 managed 状态中的唯一 `svgs[]` 文档；旧空节点身份字段保持未证实，不把 `null == null` 当作身份一致。公开几何事实仅用于核实已捕获画面与 DOM，不是独立路由最优性或合法性 oracle。

本轮不认证真人可用性、全部计划矩阵、全部目录运行、训练/推理、85/180mm最终物理可读性、字体嵌入、FPS或输入到呈现延迟。旧证据、失败、命名陷阱与修正都保持原样。
