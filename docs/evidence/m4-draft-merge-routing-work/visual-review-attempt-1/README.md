# 独立像素审查

审查身份为 AI 模拟研究使用者；真人参与者计数为 0。本目录由独立像素审查角色写入。审查者不操控共享浏览器，不修改产品代码、原生采集文件或历史封存证据，不运行模型。

原生采集由 root 进行。只有 root 明确提供冻结 manifest 后，审查者才读取本轮 JPEG 并以实际 `view_image` 观察形成逐图结论。清单校验与公开 DOM 读取用于确认输入和解释截图边界，不能替代像素通过。

每张截图单独检查可见节点与端点、连线穿过节点、不同来源交叉、不必要弯折、箭头辨识、文字与端口可读性、视窗裁切和缩放。四向节点移动与四向画布平移分别记录；截图上的 zoom 或边数与 DOM 不一致时保留失败，不从文件名推定内容。画面中不可见的节点或连线不作通过结论。

完整机器收据与逐图判断将另行写入本目录。此说明不表示本轮视觉验收已经通过。
