# Bc 构建的独立 AI 像素审核计划

本轮只审核根代理以受支持浏览器 UI 从独立 8968 服务采集的新构建证据。历史 `index-Cr_xKW9U.js` 的 39 张截图不计入本轮，待真人验收席位和评分不修改。

预期 36 个基线：Transformer L0–L3、MLP L0–L1、ResidualCNN L0–L2，共 9 个实际前沿，每个采用 paper/monochrome 与 85/180 mm 的 4 种组合。另有每模型 1 个独立编辑后案例，合计 39 张。精确展开身份、节点数、构建哈希和 spec 绑定在 `expected-frontiers.json`。

每个原始截图会通过 `tools.view_image` 单独实际打开并审看。截图、DOM 和 browser Scene 在审看前后均绑定 SHA-256 与字节数。逐项记录标题、纸面完整边界、层级轮廓、宽度/主题显示状态、图例、裁切、遮挡、模态框，以及编辑后批注位置。DOM 对照只证明记录字段，与像素可读性结论分开。

深展开适配视图的小字可能无法读清；这种情况明确记录，不从元数据推断细节标签、端口语义、共享/重复身份或准确连线端点。若截图过时、配置不一致、纸面被裁切或存在视觉问题，保留原始证据并立即回报根代理，不给原图重新贴标签。

AI 审看不能充当真人研究使用者或出版审看者；浏览器适配截图不能证明实际 85/180 mm 的出版可读性、导出实际绘制一致性或性能门槛。M4 真人验收仍待完成。
