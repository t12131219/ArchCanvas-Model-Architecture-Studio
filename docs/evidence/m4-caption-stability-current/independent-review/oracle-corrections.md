# Independent review corrections and preserved failures

This directory audits static captures of one source-backed Transformer, saved
document revision 20. It does not execute a model or operate a browser. Relation
counts are neither product test counts nor additional models, users or human
publication reviews. M4 remains partial; human participants remain zero.

`before-audit` is the preserved original label regression: 2535/2599 relations,
64 default memory labels missing. `label-only-audit` is the independent frozen
label repair: 2708/2708, no routes, public ports, canonical facts or histories
changed for the same detached inputs. Its 24 nominal caption geometry failures
have explicit layout diagnostics. Neither result grants global visual quality.
