# 小白反馈回归的独立审看方案

角色：AI 小白代理只读审看。本轮代理 CUA 返回空浏览器清单，不能自主操作 UI；根代理将从独立 8946 服务采集真实 DOM 与截图，结果需分别标记“根代理采集 / 子代理审看”。前一轮 8936 / CVO 记录不改，不把当前静态代码推理当作浏览器结果。

根代理通知 final 构建冻结后，采集证据按以下顺序审看：

| 回归 | 可审查通过条件 | 必须保留的失败边界 |
| --- | --- | --- |
| 四节点空白闭环 | Input → Linear → ReLU → Output，经可见端口真实连接；100% 下点按连接排版后无需额外 fit，四节点及全部路径在 viewport 内；截图/DOM绑定当次构建。 | 不能只看 zoom 百分比，需检查 Output 的实际 bounds；安排只增加一次历史，undo/redo保存拓扑/参数。 |
| 重复 label | 两个不同稳定 ID 的 Linear 同叫“全连接”，上游 16→32、下游错误 16。生成前选其他节点，错误后定位下游那个，中文描述、in_features 字段、input 端口和该节点均明确标记。 | 不以 label 首匹配定位；定位不改变 draft revision；切换选另节点后诊断仍有可返回定位入口。 |
| 字段修复 | 最后输入 32 后直接点生成/保存，生成源码使用32，错误标记解除。 | onBlur/Enter提交和最新currentRef顺序需真实观察；不能用旧值成功掩盖未提交文本。 |
| invalid raw文本 | 以空、abc、shape `1,` 触发本地无效；save/generate不可执行，并提示修正或Escape恢复。 | 不得无提示地使用上次有效值生成；Input shape数组在保持选中节点后移动/改显示名，不可因为对象clone自动丢弃raw无效文本。 |
| 缺失模块搜索 | Attention 和随机词均显示无匹配与当前支持边界，清空搜索恢复17；卷积中文仍匹配Conv2d。 | loading与search-empty必须区分；17只是实际目录数量，不等同完整DL-Playground。 |
| 重开与初次校验 | 保存重开恢复完整图；UI合法修改出的语义无效draft返回制图再进入搭建，首次校验仍按稳定ID和字段定位，中文错误可审查。 | 初次catalog validation必须用匹配catalog，不能因为catalogRef=null丢target；不得直接写storage造状态。 |
| 完成闭环 | 保存、重开、生成具体Python、打开新工作副本、保存论文图均完成，静态/未执行边界可见。 | 不缩水成只看一条错误提示；模型不能执行，不操作真人席位/用户端口，不替代真人M4门禁。 |

异步陈旧错误（人为网络延迟）和全部模块覆盖若工具无法真实制造，则标未验证；不能通过直接业务API或隐藏状态注入来补证据。
