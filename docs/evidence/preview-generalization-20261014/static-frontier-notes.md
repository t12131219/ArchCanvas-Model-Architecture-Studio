# Static recursive-frontier verification

Only the formal JavaScript engine under `studio/public/preview` is evaluated. Python model code is never imported, instantiated, or executed. The prototype is unchanged.

The catalog has 115 active entries and 115 historical entries. One active routing-lab entry has no registered JSON graph, so the complete registered-graph matrix contains **229 cases**. Historical cases are not silently deduplicated.

`check-preview-frontiers.cjs` exercises initial, all-open, all-collapse and all-reopen states. Mixed runs choose real nested containers by hierarchy depth and child count and open every ancestor through `SummaryRecursive.toggle`; leaves are never put in the open state. Every stage records independent source, layout, edge, preferred-clearance, constrained-fallback and label checks, and hashes the unchanged source authority. Close/reopen also compares exact node and route geometry. Reports pin the engine, catalog, graph inputs and source-authority bytes.

`baseline-v11`, `pre-wire-normalization-v12`, `targeted-v12*`, `mixed-diagnosis`, `v13-target`, `v13-wire`, `v13-exterior2` and `v13-firstlegal` are intermediate diagnostic evidence. They must not be combined into a release pass claim. In particular, the first two deep VAE/CCVAE mixed runs timed out; the later `v13-firstlegal/mixed-report.json` completed both cases and all 30 stages, but precedes the final manual-knot and impossible-interface guard changes.

`historical-fixed-interface-conflicts.json` records seven historical cases with 14 independent-wire pairs from the pinned `v13-wire` artifacts. Every pair ends at the same fixed target point with the same required orthogonal approach and a positive minimum arrow terminal of at least 9 pixels. Two independent wires therefore must overlap for at least that final distance under those recorded policies; changing the source port or exterior detour cannot resolve the final ray. One graph-attention route additionally has an undeclared boundary and crossing-order violation. This is a conflict among the old presentation policies and strict independent-wire geometry, not evidence that the producer values are aliases. The bindings are preserved and no alias is invented. The final generic preflight returns an explicit failure before searching such a mathematically impossible endpoint combination; callers retain the last valid frontier.

`previewWireIdentity.test.ts` verifies explicit producer/port equality without splitting opaque canonical identifiers or truncating colon-containing fields. `previewGeneralizedFrontiers.test.ts` covers five model families' exact frontiers, five mixed nested families, four orientations, a fixed-port exterior detour around titles, ordered manual knots and the impossible-interface preflight with shared-wire and separate-slot counterexamples. `previewFrontierRoutes.test.ts` covers nested attention, memory buses, residual gates, fold/reopen and presentation-cache migration. The final matrix must be regenerated against the final frozen engine hashes and reported without treating rejected states, timeouts or constrained fallback as passes.
