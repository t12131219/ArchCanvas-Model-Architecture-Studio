# 最终构建全矩阵采集中的像素观察

本目录是进行中的AI逐图观察，**不是封存矩阵，也不宣布完整覆盖**。`report.json`按实际打开的截图记录caseId和字节摘要；计数可能落后于采集中的live列表。只有root正式collect后的manifest能报告最终文件覆盖。目录中的full字样不代表已经完成。

逐图核查可见页头宽度/配色、可见inspector active状态、整体展开形态、整页和图例是否入窗口、是否残留模态框。精确身份由后续collector从实际Canvas重建DOM另核，tiny文字逐字、源参数、全部路由、resolved font和物理印样均不由本观察认证。`humanAcceptanceCertified=false`，人工审美仍pending。
