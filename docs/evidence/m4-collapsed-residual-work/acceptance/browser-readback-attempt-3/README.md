reports all twelve CNN L0/L1/L2 × paper/monochrome × 85/180 cases complete and
supplies current core observations. Root's pure current core outputs are observed
comparators, never expected geometry. The helper does not import product code,
operate a browser, run tests/build/model code, or edit any input.

Input directories are `m4-collapsed-residual-work/browser-after-union` and its sibling
`core-after-union`. Every case's actual Canvas, stored envelope, public SVG/DOM,
fit/local screenshot brackets and UUID SVG/document/receipt are read. The special
L0 paper180 reopen action's actual session export files are read separately.
Copies must match their original session bytes. New JS and unchanged CSS hashes
are checked against exact identities. All read inputs receive final hash readback.

Old au3 gold Canvas/Scene at the exact same frontier, page width and preset are
read directly. No old baseline object is rewritten. Revision differences are
recorded explicitly; every other complete matched Canvas field remains exact.
An additional common L0 paper180 comparison reports all page/expanded/layout
differences in full, while matched frontier geometry, source, appearance, pins
and layouts remain protected by the exact case comparison. Scene revision is
bound to the actual Canvas; all other matched protected Scene fields are exact.

271.4/4 and 235.4/4 respectively, and both new routes require38/0. L2 routes
remain exact with visible Add right targets. Complete independent route parsing,
canonical port binding, endpoint positions, nominal bodies, repeat +3.5/+7

are checked. Same tensor and role/style splits receive no pair exemption.

Actual publication/core XML may differ solely in independently checked root mm
number formatting. Complete browser interactive XML compares to complete core
interactive XML. Canvas/revision/metadata/routes/styles are never normalized.

Run once after root's signal:

```bash
python docs/evidence/m4-collapsed-residual-work/acceptance/browser-readback-attempt-3/audit.py --complete-signal root-confirmed-12-cases-complete
```

no failed report is overwritten. This helper certifies bounded artifact,
canonical geometry, export and saved-envelope consistency. It does not review
pixel aesthetics, real physical size, resolved fonts, PDF/PNG fidelity,
performance, human usability, full39case matrix or numerical model correctness.
