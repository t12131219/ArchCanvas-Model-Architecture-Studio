# Collapsed-target residual proposal

This is development design evidence for the two owned product files. The prior AU3 matrix, work directory, seals and independent audit remain frozen. The implementation was read against the formal project's AGENTS.md, archcanvas Skill and its actual runtime contract; no failed-prototype source or runtime was used.

The observed detour originates in `scene.ts`: non-data edges receive a side corridor even when a residual's real Add target is hidden in the nearest collapsed container. The existing router only refines blocked paths or paths under crossing/overlap pressure. A safe but unnecessarily long residual has neither trigger. The change adds a narrowly evidenced proposal, preserving the old preferred route as its fallback.

## API and evidence

`RouteRequest.canonicalTarget?: { nodeId: string; portId: string }` is optional. Scene fills it only when all represented canonical branches share the exact hidden target and its actual input port; the rendered target must be a collapsed expandable ancestor. Source resolution, tensor, role, appearance and every canonical edge ID retain their existing checks. Bundled projected branches with heterogeneous canonical targets deliberately keep the existing policy.

Router does not trust this new field alone. It requires actual source and target ScenePort facts at the exact requested coordinates, complete canonical-edge coverage and matching canonical bindings. The target port must be a proxy and the displayed node must be collapsed. Candidate routing changes only `path` and the derived label anchor. Source/IR facts, node arrangement, public ports, identity, style and canonical branches are untouched; data and residual edges sharing a tensor retain separate projected paths and ports.

## Candidate and acceptance

Only forward residuals with bottom-to-top port normals and at least 12 world units between endpoints participate. Three bounded V-H-V proposals use the vertical midpoint or either six-unit lead. Identical x coordinates simplify to a straight arrow. The exact existing serialized endpoints are retained; they must equal the scene's tenth-unit or fallback's hundredth-unit projection of the immutable public ports.

Acceptance requires strictly shorter Manhattan length, no additional bends, unchanged endpoint normals, no reversing segment, and no penetration of any relevant body/front-card/backplate or expanded ancestor header. Unrelated expanded containers retain the router's existing body-obstacle policy; source/target ancestor interiors remain the allowed owning frame space. Every other edge in the current complete batch is checked individually, including same-tensor branches. Crossing-pair count, crossing-point count, overlap-pair count and overlap length may not increase for any affected pair. Intermediate polyline vertices count as intersections; only whole-edge endpoints are excluded. This stronger mode is confined to the new pass and does not change the old generic or memory-family strategy.

The pass runs after existing generic/family routing so later generic refinements cannot invalidate a newly accepted proposal. It also runs when there is no generic conflict pressure and when the batch has one edge. All existing routing-budget literals are unchanged. Budget exhaustion, unsupported target evidence, bad obstacle clearance, insufficient gap, upward routes, expanded targets, memory or mask roles leave this proposal inactive. This is a bounded improvement, not a general shortest-path or route-aesthetics certificate.

## Development observations

The first probe preserved all nine source frontiers but exposed an endpoint precision mismatch: preferred paths already use one decimal while ScenePort x values can be fractional. The next probe explicitly checked that existing path endpoints are valid serialized public-port projections before retaining them. Both probe attempts remain present.

With the final whole-polyline guard, the trusted renderer changes only two routes across the nine frozen baseline frontiers: CNN level 0 residual edge 9 goes from length 271.4/four bends to length 38/zero bends, and CNN level 1 residual edge 18 goes from length 235.4/four bends to length 38/zero bends. All node/port/semantic facts remain byte-equivalent as parsed objects. CNN level 2, both MLP frontiers and all four Transformer frontiers retain their exact paths. No blocked-route diagnostic was introduced. Probe 3 confirms the intermediate-vertex guard preserves probe 2's complete Scene results.

These are trusted-renderer development observations, not user-model execution, independent test acceptance, browser pixel review, calibrated publication, or performance evidence. The root owns focused/full tests, strict TypeScript/build and the new browser regression round; an independent agent owns the geometric oracle.
