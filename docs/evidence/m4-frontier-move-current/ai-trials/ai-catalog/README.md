# AI 模拟模块库与从零搭建审查

执行者为 `/root/ai_catalog_frontier`，属于 AI 代码、fixture 与历史图片审查，**不是当前构建的原生浏览器试用，不是真人研究参与者**。本阶段未打开作者模型页面、拖入模块、保存新草稿或操作共享浏览器。真人仍为 0，M4 仍为 `partial`，M5 为 `not_started`。

正式库确有 **17 个基础类型、11 类、34 个参数字段，以及 3 个透明网络起点**：最小 MLP 5 模块/4 连接、小型 CNN 8/7、残差 MLP 6/6。正式 `.venv` 仅读取 catalog 数据，结果保留在 [formal-catalog.json](formal-catalog.json)。网络起点展开成普通模块与连线，能够逐项编辑；不增加新的模块类型，也不代表模型执行通过。

从零搭建的入口和流程可以在当前源码中追踪：顶栏“搭建模型”进入独立草稿；空白画布提示添加 Input；左库按基础模块/网络起点切换，中文或英文搜索跨两种列表；点击添加或拖入；选右侧参数；输出端口连接输入端口；静态检查、保存、生成新源码并审看后打开新的制图副本。界面提供撤销按钮和 Ctrl+Z，添加整个起点只占一个历史步骤。现有 focused tests 重跑为 **17/17 和 19/19**，均无 fail/skip/cancel；这些是当前 468/468 正式 suite 内的既有测试重复检查，**不能相加为新的产品测试或使用者**。完整机器可读范围、源文件定位和有限 SHA 绑定见 [report.json](report.json)。

这是类似用户要求的左侧可拖入模块库，但目前范围适合有界 MLP、CNN、残差和张量分支草稿。Sigmoid、Tanh、Conv1d、AvgPool2d、BatchNorm1d、MultiheadAttention、LSTM 明确列为不支持；Softmax、通用 Reshape/Permute、转置卷积、上采样等也没有登记。是否“足够常用”取决于目标模型，目前不足以覆盖任意深度学习网络；逐类生成、执行与初学者学习效果均没有本阶段认证。
