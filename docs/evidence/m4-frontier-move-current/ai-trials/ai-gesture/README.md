# AI 手势与布局审查（frontier move）

本目录是一次**AI 模拟审查**，不是 3–5 位真实研究者的验收，也不是出版尺寸审看。审查者只读取已保存的公开 DOM JSON、完整 SVG 和 PNG；没有执行新的鼠标事件、网络写入、内部状态读取、模型执行或源代码写回。`humanParticipantsAdded` 和本次浏览器输入均为 `0`。

审查输入绑定、四向与撤销结果、展开/折叠状态、路线几何统计和限制见 [report.json](report.json)。可复算脚本是 [geometry-audit.py](geometry-audit.py)。脚本只解析 SVG 的绝对 `M/L/H/V` 路径、公开节点矩形和公开相机缩放，不导入 Studio 产品模块。

本次执行的 stdout 保存在 [geometry-audit.log](geometry-audit.log)。

四向操作的公开 SVG 结果均符合当前视图范围：

| 操作 | 目标 `Linear 1` 世界坐标变化 | 其他节点变化 | 撤销 | 源/IR 摘要 |
| --- | --- | --- | --- | --- |
| 右移 | `(+24, 0)` | 仅目标体 | 与基线的 body/route 均 exact | 稳定 |
| 上移 | `(0, -24)` | 仅目标体 | 与基线 exact | 稳定 |
| 下移 | `(0, +24)` | 仅目标体 | 与基线 exact | 稳定 |
| 左移 | `(-24, 0)` | 仅目标体 | 与基线 exact | 稳定 |

撤销证据支持四个方向回到同一基线；固定的 `features` 输入体在所有状态均为 `(80,154,194,62)`。展开时 `output` 为 `(80,1756,194,62)`，折叠时为 `(80,354,194,62)`，两者是不同 frontier 的合法位置。`14-collapsed17-fit` 是 settled 的四体视图（rev17，97% fit），`15-reexpanded18-fit` 是 settled 的 304 体视图（rev18，13% fit）；重展后 body/route 与 expanded 基线 exact。保存 rev16 与重开 rev16 的 SVG 字节相同。

有两类视觉风险需要保留给路线优化和真人审看：

1. expanded/reopened 公共 SVG 有 302 条可见路线；独立中心线统计为 **71 个不同 edge-pair 的严格内部正交交点**、**4 组正长度共线重叠**，其中 286 条路线是 5 段、4 个转弯。统计排除端点接触、描边宽度和箭头头部，不能证明每个交点或转弯都不必要，也不能给出全局最少相交解。300 个叶节点之间没有矩形内部重叠，路线没有穿过无关叶节点体内的结果只适用于未发生异常偏移的状态。
2. `06-down24-current` 的下移 SVG 额外出现 9 条路线段进入无关叶节点的矩形内部（主要是 `edge:3`、`edge:41` 穿过 `network.37`，并涉及 `network.2/38/39`）。这说明“只移动当前对象”在该四向极端操作下会造成可见连线侵入；同名 PNG 是旧相机/旧 DOM 的初帧，不能用它否定 SVG 证据。

settled PNG 的可见性也有限：折叠 fit 图能读出标题、输入、网络和输出，箭头为直线且没有明显拥挤；重展 fit 图仅能作为全局 overview，13% 相机下叶节点文字不可读，不能据此宣称出版可读。此前 `10/11/13` 以及部分方向的 PNG 与同名 JSON/SVG 存在一步滞后（例如旧 `10` 截图仍显示网格、旧 `11` 截图显示折叠图），这些失败/不同步证据均保留，没有覆盖或改绿。

本审查不覆盖 presented FPS、真实字体栅格、出版物实际尺寸、全局 route 最优、美观判定、真实用户从零建模或预制模块可用性。M4 的真人席位、出版审看和性能/可读性 gate 仍保持未完成。
