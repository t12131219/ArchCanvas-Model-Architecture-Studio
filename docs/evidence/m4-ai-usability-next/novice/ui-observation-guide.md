# AI 新手模拟的 UI-only 观察顺序

这是一份待执行的观察提纲，不是使用成功或界面现状。子代理当前 CUA 无浏览器能力，主代理将仅在新的8911标签页实际操作并交回截图/visible DOM。收到真实界面之前不读取产品源码或 API 来找入口。

1. 首屏：画布是否空白、有没有默认示例、新建/空白模型入口，以及主次操作的名称。先保存首屏，再决定点击。
2. 左侧：是否有常见模块库或组件列表，是否按 Input、Linear、ReLU、Output 等基础块分类；若是既有模型树，记录它的用途，不当成可拖入库。
3. 预设/新建：只打开实际可见菜单，区分视觉页规格/颜色预设与新模型模板。尝试可见的新建入口；不存在时记“未发现”，不要猜隐藏 URL 或 API。
4. 建模：若存在可拖入基础块，依次尝试 Input→Linear→ReLU→Linear→Output，记录每次实际新增、端口连接与参数编辑结果。不存在基础块入口时停止该构建路径，保留现场和阻碍。
5. 示例：从实际可见入口打开一个简单示例，检查选中对象后是否能自然找到显示名、颜色、位置、参数和连接入口。任何真正改变模型语义的提交仍遵守正式审批，不通过源码/API绕过界面。
6. 结果：从零搭建与编辑既有示例分别报告；区分入口缺失、没有发现、点击失败、原生拖动能力缺口和尚未执行。

AI 新手混淆、实际点击和截图可形成自动化可用性观察。它们不能成为真人完成率、真人审美评分或真实输入性能采样；工具/代理等待时间也不当成研究任务耗时。
