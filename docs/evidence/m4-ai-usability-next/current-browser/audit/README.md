# Independent current-build browser audit

This directory contains the independent checker and results for new captures under `current-browser/` only. No pass is inherited from the earlier `index-Cr_xKW9U.js` scope. The predeclared candidate is `index-DgtJrWU9.js`; its declared SHA-256 prefix is `84baa013`. The complete served-build hash must be captured and bound before this audit assigns build provenance.

`check_directional.py` and its 20-counterexample `test_directional.py` are exact copies of the independently authored JSON/XML checker. Their origin and bytes are recorded in `checker-provenance.json`. They import no Studio renderer/history/observer, run no model, operate no browser and start no service. Any compatibility repair uses a new checker copy/provenance entry and retains the initial files and original inputs.

The new journal must identify the same canonical MLP Linear target and separate four before/moved/undo/redo node cases from four before/panned/reversed camera cases. Public source/IR/facts, rendered nodes/bindings, actual visible ports, explicit path endpoints, other leaf coordinates and full SVG restoration are independently compared. Captured expanded/pinned memberships are checked explicitly; missing fields are missing evidence. The camera is outside CanvasDocument undo history.

The up-32 case is deliberately a conflict probe, not an aesthetic pass. The body/header overlap must remain measured while the public warning and actual settled screenshot are inspected separately. Undo or the explicit restore must restore the baseline coordinates and remove the corresponding header warning. A warning does not make the conflicted layout publication-ready or prove that all text/route collisions have been detected.

Actual export evidence requires the current interactive SVG, actual service-written SVG bytes, export receipt, public generated-file and download-link records, and the captured browser actions/status. The standalone checker can compare exported metadata, objects, styles and appearance while excluding known interaction controls. It cannot establish download delivery merely because a link exists; the report distinguishes file generation, published download availability, clicked download and confirmed delivery.

Save/reopen needs the actual stored document bytes and before/reopened public SVG/canonical facts. A saved-button action, a success toast or a reused in-memory SVG alone does not establish persistence. Explicit input paths, revision, document identity and actual artifact hashes bind the comparison.

PNG review remains separate from stable DOM consistency. New settled PNGs are compared to their paired inspector coordinates/footer revision and complete SVG. These snapshots do not establish synchronized presented FPS or active pointer-cancellation. Failed/incomplete captures are retained outside passing coverage.

Run this copied checker on the root agent's completed new journal only after capture completion is declared. Use new result names, retain all prior raw evidence/seals, and record zero human participants. This AI evidence cannot satisfy the human/publication M4 acceptance gate or certify advancement to M5.
