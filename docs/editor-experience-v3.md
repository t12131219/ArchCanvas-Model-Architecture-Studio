# 编辑器体验 v3：需求与实现计划

2026-10-07。先记录本轮需求和验收合同，再修改正式工程。正式 runtime 从头实现，不使用失败原型或其回退链路。上一轮统一编辑器的检查只作为旧版基线，不证明本轮实现。

## 目标与通用规则

1. **连线分离。** 解决同一横向/纵向通道上的箭头重合、贴边和不必要绕行。路由以 canonical tensor/port binding 和可见层级为输入；不依赖 Transformer、Encoder 或某个夹具名称。不同 binding 应有可辨识的通道和箭头，同一 tensor 的 fan-out 也应能追踪各个下游。保留节点手动锚点、端口身份、残差/memory/mask 角色和父子投影覆盖。不能仅隐藏冲突或降低诊断阈值。遇到真实空间不足须给出诊断。
2. **隐性模型根容器。** 展开的架构根容器保留层级身份、布局约束、折叠收紧和缓存，但编辑/浏览画布不绘制其背景、边框、标题和根端口装饰。适用于任意具有相同结构的模型，而非名称判断。模型名称和来源摘要移到画布外的工作区标题。层级面板仍可选择/折叠根；折叠后的根卡片仍可展开。内部实际模块容器继续可见。
3. **统一视图/编辑切换。** 用一组固定位置的“视图 / 编辑”切换替代并列的“编辑当前模型 / 从零搭建 / 返回制图 / 生成后再打开”等主要路线。从空白编辑开始，可一键静态生成并浏览最新模型；从当前源码视图进入编辑保留布局、选择、相机、工具与各自历史；返回视图必须展示当前编辑结果，不能悄悄丢弃修改或返回旧图。生成失败保留编辑状态和草稿，定位原因；异步状态防止重复请求。未修改时复用当前视图；继续编辑复用对应草稿而非重新导入。原始源码不被这种切换覆盖。顶部按“工作区选择/新建、模式、保存/导出”组织，源码导入和高级动作移入明确菜单。
4. **悬浮图例。** 浏览画布的节点图例及连线角色图例放在角落的可收起浮层，不随世界坐标平移、不进入框选、不影响 fit 边界。图例内容仍来自同一文档及当前实际线型，颜色/名称/顺序编辑继续持久化。模型标题和图例不是无限画布中的几何对象。出版导出可保留独立的标题/图例版式，编辑器浮层不进入 SVG/PDF/PNG。
5. **源码自定义模块。** 编辑模式提供源码窗口，输入 Python nn.Module 类、类名及构造参数，静态预览可连接的具名输入/输出，再加入草稿和自定义模块目录。模块定义、源码、构造参数和静态边界合同随草稿保存/重开，可重复插入，可与原子模块连接，生成后源码完整且重新分析验证绑定。支持多输入与多输出，未知内部明确标记；不能把未知结果说成 shape 推导成功。源码不 import/exec，错误和不支持的构造合同在预览中明确报出。模块名隔离避免冲突，禁止修改原始源码目录。

## 实现分工

- 路由核心：通道重合独立诊断和泛化通道分配/候选路线，验证整体几何和 canonical attachments。
- 展示核心：保留根约束的 editor presentation，区分工作区几何与 publication 装饰；浮层内容由现有 scene/document 派生。
- 工作区 UI：统一模式栏、一键生成浏览与草稿恢复、外部标题、悬浮图例、源码模块窗口。
- 自定义模块 backend：静态源码预览 API、持久化合同、命名空间生成和独立重新分析验证。

## 验收

| 需求 | 必须检查的实际结果 |
| --- | --- |
| 连线分离 | 多输入、多输出、fan-out、残差、不同 tensor 平行通道、层级展开/折叠和四向移动；比较整条线路重叠/交叉、端点和事实。实际浏览器看总览和局部，不能仅以测试数判定视觉完成。 |
| 隐性根 | 至少 MLP、CNN、Transformer 和新的自定义名称模型；展开时 canvas 无根框/重复标题，折叠/重开位置和收紧规则保留。 |
| 一键切换 | 空白搭建→视图→编辑、导入源码→编辑→修改→视图、多次往返、保存重开、无改动复用、生成失败留在编辑、撤销重做/相机/多选连续性。 |
| 悬浮图例 | 角落展开/收起、pan/zoom/fit 后仍固定；节点/连线角色正确，颜色/名称修改保存重开，导出无浮层。 |
| 自定义模块 | 源码窗口实际预览/插入/重复插入/连接/保存重开/生成/浏览；独立检查具名多输入、多输出、参数、命名冲突、语法错误和不支持结构；生成源码重新静态分析，不执行模型。 |

所有新增合同运行专项测试，最终运行 Studio 完整测试、TypeScript/Vite build、相关 Python/导出测试，并记录当前源码/产物和实际浏览器证据。M4 真人/出版审看仍保持原状态，AI 浏览器复核不计真人；本轮不得宣称全局最少交叉、任意 Python 数值等价或模型执行通过。
