# ADR 0001：独立实现与视觉 Alpha 的验收边界

状态：采纳，2026-10-04。

## 决策

正式项目从需求、框架公开合同和独立人工关系基准开始编写。失败原型不是依赖、运行回退或迁移基线。当前复用登记为空；没有已认证的原型代码片段。

第一批实现以可查看、可调整、可保存、可导出的视觉 Alpha 为交付目标。事实图与 `CanvasDocument` 分离；显示名、样式、图例、注释与位置属于视觉文档，不能改变源码事实。源码变换、批准写回与运行观察需要各自的后续验收，不能由可见图形或静态分析成功推断。

## 独立性证据

`scripts/check_independence.py` 将正式目录复制到 `/tmp` 下的独立发行副本，排除虚拟环境、缓存、Git 元数据和相邻项目。Python 子进程使用隔离模式、关闭 site 自动载入，并仅添加该副本的 `src`；检查模块实际路径，再运行 capabilities 和三个源码 fixture 的静态分析。可选 Studio 构建使用正式项目安装的 npm 依赖副本；该步骤证明独立构建，不等于干净网络安装或宿主认证。

脚本不会移动或删除原型目录，也不使用它的解释器、CLI、源码或输出。

## 边界

人工关系基准独立于分析器输出。没有运行模型时，shape、执行分支和数学细节不得登记为已运行证明。保存版本冲突必须拒绝覆盖；存储版本与文档操作 revision 是两种不同的版本。

发布质量、三级展开、空间连续性和三宿主认证仍需真实浏览器与用户任务证据。能力矩阵只记录已实现和已验证的项目。
