# Production Capture Directory

This directory contains the generated production side of the P0 visual
acceptance. Fourteen SVG/PNG pairs correspond to the files under `../build`;
the `runtime-*.png` files are real Studio browser captures at the required
desktop/mobile viewports and dark theme.

The captures are generated by `npm run acceptance:p0`,
`npm run acceptance:p0:visual`, and the P0 Playwright test. They are evidence
only: the production runtime does not read this directory or the Scene Visual
Lab build.
