# Stage 8 Acceptance: Pattern Packs and Holdout Generalization

## Delivered

- Versioned Pattern Pack, semantic overlay, match receipt, and preview-only candidate protocols.
- A deterministic declarative matcher whose hard structural/dataflow constraints cannot be
  rescued by weak naming hints.
- Five builtin packs for Transformer, Autoformer, iTransformer, PatchTST, and TimeMixer, including
  positive, negative, predicate-mutation, and Exact IR digest-invariance tests.
- Digest-locked workspace packs, conflict-to-generic behavior, stale/duplicate rejection, and
  refusal to execute third-party matcher code.
- Candidate review that records match basis and counterexample risk while granting no shell,
  network, source-write, installation, or activation permission.
- Overlay-aware publication and Studio rendering that preserves the canonical node, tensor, edge,
  and port sets.

## Holdout Matrix

All holdouts run with Pattern Packs disabled and have no fixture-specific architecture profile or
dedicated pack.

| Family | Fixture | Recovered structure |
| --- | --- | --- |
| CNN/ViT | `VisionTokenStem` | convolutional patch projection and token mixing |
| State-space | `SelectiveStateCell` | input drive, carried state, and state update merge |
| GNN | `NeighborhoodExchange` | local/neighbor projections and message aggregation |
| Diffusion | `TimestepDenoiser` | noisy signal plus timestep conditioning |
| MoE | `DualExpertRouter` | router, two experts, merge, and output projection |
| Time-series | `SeasonalTrendForecaster` | trend/seasonal branches and recomposition |
| Custom hybrid | `CrossBlendRegressor` | context blend and residual forecast path |

Each matrix row passes source identity, evidence-backed semantic closure, zero blocking
diagnostics, generic arbitrary-depth hierarchy compilation, exact canonical-set coverage, and geometry validation. The
test also requires evidence on every recovered node. Opaque boundaries, when produced by other
unsupported-control-flow fixtures, remain acceptable only with an explicit unresolved reason and
declared boundary capabilities; none of these seven holdouts needs an opaque fallback.

## Trust Evidence

Every analysis writes the semantic overlay, Pattern Pack receipt, and candidate review. Disabled
matching loads no packs. Ambiguous matches apply no annotations, and candidate matches stay
preview-only. Tests cover weak-name non-rescue, workspace digest locks, ambiguity, candidate
non-activation, overlay binding, stale overlay rejection, and the real CLI `--no-pattern-packs`
route.

The holdout matrix materially improves the previous single-model evidence. It still does not prove
arbitrary Python control flow or every production implementation of these model families; those
cases must continue to resolve through evidence-backed generic recovery or an auditable boundary.
