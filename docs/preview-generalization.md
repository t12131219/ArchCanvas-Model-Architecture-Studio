# 通用预览排布与交互修复

这次修复应用于 Summary_Merge 迁移后的共同布局、路由和 Studio 同步机制，覆盖已有模型与导入源码图。模型名称和案例 ID 不参与路由修复规则。Studio 的上、左、右面板、源码编辑和图例编辑入口继续通过原有桥接与预览互通；预览面板投影保持 opaque，视觉操作不授权源码事务。

共享分支的长度计算统一考虑所属节点、原始坐标和向内端口。完整源视图和混合展开视图使用一致的边界通道规则。局部通道候选保留记录的接口、源端口和目标端口，在完整源码、几何和障碍校验后才能采用。不能用降低安全距离或允许违规连线来制造通过结果。

连线身份依据明确的生产者与端口证据统一；完整 tuple 槽位、返回字段、共享实例的各次调用分别保留。没有端口字段的 canonical 标识按原值保存，不能凭名称里的冒号推断别名。独立值共线时尝试合法平行通道，不把视觉重叠解释为求和或共享值。

展开容器的标题与图元说明同样参与路由和最终验证，因此拖动、主动布线、JSON 与保存状态恢复也遵循标题避让。贴框路线可只移动拥挤子段，保留固定接口前后的接近方向。短子路径与平行线修复使用共同的有界校验预算，只有全部约束通过、独立交叉和去重后的线间接触点不增加、平行线拥挤程度不恶化时才能替换。转角落在线上也会计为接触，不能用折点逃过严格交叉统计；共享源码值与已许可的完整共享表达继续排除，真实终端由端口约束检查。有序手动折点和共享分叉保留。候选排序沿用原型的长度、转折和交叉成本。

混合展开时，同一父容器中在来源模板里明确居中、纵向分开的节点保留中心轴；不同列和分支仍保持各自位置。独立叶节点只有在全部连接进入同一展开根容器、明确记录一致接口侧且新位置无碰撞时，才从错误侧移动到接口侧。手动偏移最后叠加，完整注册视图保留原型节点位置。规则不使用模型名或案例 ID。

混合展开容器的边界通道按实际可见、具有源码身份的独立连线预留空间，共享值只计一条通道。这样多条返回线不会被固定容器间距挤进狭缝。注册视图的原始几何保持不变；固定端口附近的短接近段仍受来源接口约束，不能为了视觉分离而移动源码绑定。

增加通道空间使展开边框不对称变宽时，仅在来源明确记录了真实生产者同一值的多个边界分支、且有真实居中终端时，采用内部操作轴作为同列布局的基准。容器自身的入口代理、单条居中连线和独立 tuple 槽位不构成这项授权，继续按来源框架对齐。入口代理不能用自身端口为自身的移动提供循环依据；真实生产者跨越单层边界仍可保留共享输入直线。这项收窄消除了 PatchTST 已发现的纯长度退化。移动事务仅将已稳定的合法连接保留为占用通道，尚未修复的非法受影响连接会在事务内继续处理，最终完整图仍必须通过连线、分叉和来源校验。版本 18 会重建较早的缓存视图，并保留展开选择和手动位置。

全部既有平行通道避让和短路径简化完成之后，最多 16 个末端短段候选复用相邻固定值槽位的端口接近区。只滑动已有短段，保留实际端点和手动折点顺序，继续使用共同预算中的剩余额度。只有拥挤程度下降、接触与严格交叉不增加、线长和转弯数不增加、近线数量与总长度不增加、最小间距不缩小时才能采用。先完成原有简化，避免提前滑动阻止后续删除多余折弯。这项顺序修复消除了完整矩阵中发现的 LSTM 纯退化，并保留 TimeMixer 的短平行段改善；横竖方向、反射、手动折点和真实完整清理流程均有回归检查。

自动展开在得到完整合法路线后即可采用，主动布线仍保留路径成本优化。许可端口附近优先尝试局部障碍物侧绕，避免简单通道进入完整搜索。直线或单折线路若已达到考虑进出方向的无障碍成本下界，可直接完成对应搜索段。搜索中缓存与到达方向无关的线段代价。源码包含关系错误，以及独立值被固定在同一输入末段的矛盾请求，会在搜索前拒绝，由调用方保留上一个有效视图。

候选路线成本在一次候选集内只计算一次。外部绕行先按确定性的低成本指标筛出跨端口组合的有界候选，再按原型的完整成本排序和校验；未找到合法路线时继续使用正常路由器。可选平行线清理同时限制候选生成、质量计算和完整校验次数，预算用完后保存结果，避免同一视图反复收起和打开时继续漂移。

同一次端口求解中，重复的内部接口搜索段复用完全相同的结果，包括搜索失败；缓存键包含障碍物几何和进出方向，旧式无源码身份连线还包含端口接近段。缓存最多保存 256 项，不跨路由事务使用。重合的连续接口点只有在进出方向合法时才直接完成，并保留转弯成本。

预览初始化直接使用已完成的几何建立面板文档，展开与包含展开的组合操作由预览引擎执行一个原子事务。父 Studio 投影完成后的状态，避免调用第二套布局与路由。说明文字的冲突检查和位置建议直接读取当前可见图元；常规选择说明文字也不生成隐藏的旧场景。源码回传用载入世代校验，防止 A→B→A 切换后的旧请求污染新文档。

模型载入的路由与校验交给 Worker，旧模型身份、源码、图、持久化键和撤销栈一直保留到新模型验证成功后一起发布。载入失败保留旧模型。展开、拖动和布局事务忙碌时拒绝并发修改；Worker 不可用时使用同一校验任务。

选择节点的重绘保留 SVG 图元在原有父层，避免无必要的 DOM 移动打断真实 click/dblclick。指针捕获导致双击目标变成 SVG 时，画布根据真实位置识别模块并展开；连接和折点工具不会误触展开。中键平移沿用 Studio 行为。

验证目录为 `docs/evidence/preview-generalization-20261014/`。早期基线、失败和中间构建分开保存，最终结果绑定正式 public/dist 文件摘要。父侧 CPU 投影测试与实际浏览器交互耗时分别报告，不能互相代替。

最终版本 18 的完整矩阵覆盖 229 个当前及历史案例、916 个标准阶段，以及 26 个案例、480 个混合展开阶段。当前有注册图的 114 个案例全部通过，混合展开全部通过；16 个历史案例仍因原始来源、包含关系或固定独立输入端口冲突被拒绝。相对稳定版本 16，1396 个阶段的九项指标没有新增恶化；24 个阶段线长减少，19 个阶段近距离平行段总长度减少。

这不表示相对所有中间版本的每个指标都单调改善。相对更早版本 14，ASPP 的三个阶段线长增加 87 像素，同时少四次折弯和两次严格交叉；TimeMixer 的三个阶段严格交叉多一次，但独立接触点由 14 降为 12、T 形接触由三处降为零，没有新增相交连线对或近线拥挤。相对版本 17，历史 MI-LSTM 和当前 Transformer-XL 案例的四个阶段失去提前执行末端整理时的偶然收益，当前 MI-LSTM 两个阶段近线长度增加 28 像素而少两次折弯；这些阶段均未差于版本 16。完整逐阶段对比与原始几何证据保存在 [最终验证](evidence/preview-generalization-20261014/README.md) 中。

独占测量期间，十类模型的 40 次原生展开、嵌套展开、收起和重开耗时为 150–884 毫秒，计时包括操作、稳定状态读取与校验。VAE 深层展开的桥接命令往返约 917 毫秒，此项不包含后续快照读取与校验，不能与前者当作同一计时口径。VAE 从混合展开和直接展开得到的完整视图几何一致；来源本身要求的交叉和短近线仍保留，详细限制见 [VAE 验证](evidence/preview-vae-layout-20261014/README.md)。

可复现入口：

以下命令在完整源码 checkout 中执行，使用 `studio/public/preview` 中的来源材料和开发依赖。发行包保留验证报告与部分历史隔离材料，历史隔离 runner 同样需要完整源码树；它们不属于发行包的独立运行入口。

```bash
node studio/scripts/check-preview-frontiers.cjs --phase mixed --selection docs/evidence/preview-generalization-20261014/final-mixed-selection.json --output docs/evidence/preview-generalization-20261014/recheck-mixed
node studio/scripts/test-preview-generalization.mjs --base http://127.0.0.1:8891 --phase final --output-dir docs/evidence/preview-generalization-20261014/recheck-browser
node --experimental-strip-types studio/scripts/benchmark-preview-generalization.ts --output docs/evidence/preview-generalization-20261014/recheck-parent-projection.json
python3 studio/scripts/test-preview-engine-regression.py --output-directory docs/evidence/preview-generalization-20261014/recheck-engine
```
