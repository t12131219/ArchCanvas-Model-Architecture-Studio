# Summary generic 模型目录接入

日期：2026-10-28。以 Summary 的 IR、原生语义画布及编辑副本替换重叠能力；保留 Studio 菜单、树和折叠面板。本阶段接入完整目录与预算内模型，不将大图开放或整体迁移描述为已完成。

## 数据来源与独立运行

原始 `data/semantic/catalog.json` 共 43 个模型；43 个 IR 和 1 个展示配置连同目录共 45 个 JSON 原样复制到正式 `studio/public/preview/data/semantic/`。逐文件 SHA-256、字节数和目的路径在 `summary-catalog-assets-manifest-20261028.json`。构建后直接服务正式项目的静态资源，运行时不访问原型目录、绝对源码路径或原型 Python。

`scripts/vendor_summary_catalog.py --source ../prototype/Summary_Merge` 仅用于显式维护复制；不是启动、构建或打开模型的依赖。复制时核对原始 IR schema、摘要、节点数和依赖数，拒绝路径越界及重复模型身份。原始绝对路径、静态/运行证据、覆盖限制、未知边界与失败记录留在 IR 中作 provenance，不变成源码事务绑定或可执行路径。

额外生成小型 `studio-catalog.json`，仅包含面板显示、原始资产引用和字节指纹。目录加载不预读全部 IR。原始目录保持逐字节不变。

## 面板与行为衔接

| 入口 / 动作 | Studio 负责 | Summary 负责 |
| --- | --- | --- |
| 模型 → Summary 模型库 | 打开右侧对象标签，展开“Summary 模型库”；沿用主程序菜单/面板外观 | 不再挂载原型 generic-controls 整个侧栏 |
| 搜索与选择 | 按标题或原始 id 搜索；显示原始节点/精确依赖数量、归档证据和预算说明 | 原始目录身份和所有语义对象不重命名、不裁剪 |
| 打开模型 | 限制流式读取大小，核对字节及 SHA-256；验证目录摘要、计数与 IR 一致；管理异步加载序列 | 沿用原生 `D.read → generic-build → N.accepts → openCase`，创建可搬运导入文档 |
| 初始切面 | 若有展示配置，执行与 Summary `SemanticPresentationProfile.validate` 相同的 schema/IR 摘要/revision/state 绑定检查 | 保留配置 default_state；未配置模型沿用当前原生 F0，不另写几何 |
| 层级与对象 | 读取 child snapshot，保留原生身份，沿用现有树/对象/图例/页面面板 | 维护图、切面、选区、路由、相机与 undo/redo |
| F0/F1、六档切面、角色/前沿 | 使用已有折叠控件发送消息 | 保留完整 canonical IR，原生前沿变换；路由未完成明确 pending/failed |
| 视图 → 编辑 | 沿用现有双模式切换和组装编辑折叠面板 | 从当前完整 IR 建立独立 Summary 编辑副本，原生历史与精确 operand 规则不变 |
| 保存 / 刷新 / 编辑 JSON | 沿用 Studio 保存入口及正式视觉文档边界 | 沿用已有文档存储和编辑 JSON；无需再次读取原型目录 |
| 数据损坏 / 摘要或展示配置不匹配 | 在折叠面板报告错误并恢复可操作状态 | 拒绝替换，保持当前图与历史 |

打开过程中宿主禁用模型切换、编辑和事务相关入口；异步读取受 `loadSequence` 约束，旧请求不应用到新模型。只有成功获取新 snapshot 才重建 preview-only 面板文档；不会把上一模型的 Python/CAS 身份保留给新目录模型。导入记录始终是 `sourceVerified:false`、`modelExecuted:false`，含义是本次没有新源码验证或执行；IR 内归档运行观察仍完整保留。

旧“示例与模块库”保留为专用历史递归案例入口；新 generic 目录使用主程序折叠面板，避免把原型完整 sidebar 作为默认产品外壳。正式源码示例、正式源码工作副本与事务审查仍保留。
