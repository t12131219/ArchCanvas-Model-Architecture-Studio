# 拖动后的连接与文字跟随修复

修复了仅更新端点而遗留折点造成的斜线、折返与多余末段。`SummaryEngine.move` 在同一操作内移动图元、子图元及相关路径；优先保持原直线与通道，再尝试合法直角转折和局部避障。固定端口、源 binding、IR 摘要和容器 gate 保留；无合法路径、同级碰撞或箭头末段过短的位置会回退。

跟随采用显式所属关系。`Scene.text(owner=...)` 输出附件 identity / owner / source_owner，Q/K/V 名称与形状属于各自值别名，模块标题属于模块，hidden 快照属于源 ReLU。每个附件按所属图元相对初始坐标的位移渲染；移动容器时子图元各移动一次，附件不会重复累加。点击或拖动附件文字即可选择或移动其所属图元。画布总标题及脚注固定。已有其他例子的节点内文字继续随节点移动；没有明确来源的全局说明保留为固定说明。

原生 `validate_semantics` 校验附件的来源归属，实际 XML 检查比较附件覆盖与 owner。导入 `semanticBaseline.attachments` 防止删除、改换 owner 或伪造 source_owner；标签不成为新算子。运行时还拒绝非正交、折返、错误端口法线、穿入端点实体和过短箭头末段。原始/历史 SVG 的视觉端口推断保留其证据范围，不据此声称新的模型语义。

浏览器证据：`before.png` / `after.png`、`browser-checks.json`、`browser-current.svg`（Q/K/V 局部只读 DOM 捕获）。实际拖动 K 后位移为 (34.4722, 6.8945)，K 与 [B,S,D] 使用同一位移；85 条边中 0 条无效，源码 binding 未变化。撤销恢复三者到原位，重做恢复三者到新位。再拖动 K 文字，也能带动图元及形状，全部连接保持有效。

验证结果：23 项图引擎回归、默认 Transformer 21 个源码/IR/layout/XML 损坏负例、327 个导入视图的 1,974 个损坏负例。328 个当前视图、5,538 条边的三种显示检查为 0 问题、0 对不同张量共线重叠。Autoformer、两组 TimeMixer、Transformer 详细视图完整布线均无失败；7 组原生检查通过。完整收据见父目录 validation.json。

所有验证均为静态源码和图形操作，没有执行模型。浏览器下载事件未返回，保存的 SVG 是只读 DOM 捕获，不将它作为下载成功证据。
