# Transformer 程序化示例：版式选择

两个版本使用相同的源码语义与参数身份，区别在于模块内部的展示方向。当前默认仍为统一自底向上版，上次的箭头优化结果另存为完整可选版本。

| 可选版式 | 模块内部排布 | 图3尺寸 | 查看 |
|---|---|---|---|
| **统一自底向上版（当前默认）** | Attention / SDPA、FFN、Add & Norm 的主计算链均向上 | 1600×2742 | [三图预览](generated/index.html) · [图3 SVG](generated/figure3_detailed.svg) · [说明](源码到Transformer三层架构图_对应关系与程序化布局.md) |
| **紧凑混合方向版（上次结果）** | 整体向上；Attention 内部向下，SDPA / FFN 横排；Linear→Q/K/V 张量横向连接 | 1600×2308 | [三图预览](variants/compact_mixed_flow/generated/index.html) · [图3 SVG](variants/compact_mixed_flow/generated/figure3_detailed.svg) · [当时的说明](variants/compact_mixed_flow/源码到Transformer三层架构图_对应关系与程序化布局.md) |

[打开带预览的版本选择页](版本选择.html)

上次结果保存在 `variants/compact_mixed_flow/`，包含三张 SVG 与 PNG、局部图、当时的生成脚本、Markdown、布局及检查记录、源码副本。三张图和生成脚本直接复制自统一方向之前的最终快照，保留固定 9px 箭头、至少 18px 末段、不沿边框走线，以及图3相对最初版缩高约 9.9% 的结果。

在本交付目录运行以下任一命令，即可生成对应版本；输出分别写入各自的 `generated/`，互不覆盖：

```bash
# 当前默认：统一自底向上
python3 draw_transformer.py
```

```bash
# 可选：上次的紧凑混合方向版
python3 variants/compact_mixed_flow/draw_transformer.py
```

两份脚本均静态解析源码，不运行模型。上次版通过九类检查，当前版通过十类检查（增加逐段向上方向检查）。原始快照仍保留在 `snapshots/before_bottom_up/`；可选版的文件摘要见 [保存清单](variants/compact_mixed_flow/preservation_manifest.json)。
