## 发现与修正

| 例子 | 原问题 | 正确的源码对应 |
| --- | --- | --- |
| U-Net | skip从展开的encoder外框出发 | `encN=self.encoderN(...)` 的返回，继续递归至最后ReLU或折叠block；不能取pool后的值 |
| AlexNet / GraphNet | 展开classifier / adjacency外框成为实际生产者 | 分别由最终FC logits / `register_buffer`对应的buffer图元出线 |
| VAE / ConvVAE / CCVAE | mu与logvar被画成一个公共输入总线 | 两个真实producer分别进入retain-mu与half-logvar；同源的posterior heads才是同值分叉 |
| GAN / residual | container `:in` 被当成外框中点或已处理后的值 | retained input追到进入该模块之前的真实producer；和模块output严格分开 |
| manual/fused BN | mean、var、gain都可能接到stage最后子算子 | mean来自moments保留字段，var来自variance，gain进入真正的gain乘法 |
| Flow BN / FlowSequential | 统计bundle或features/logdet字段混用 | mean、var分别接标准化/EMA；features与logdet独立传递和累加 |
| Glow ActNorm | 初始化链被画成正常仿射参数输入 | 初始化Copy更新状态；正常计算从loc/scale状态分别接shift、scale、log-abs算子 |
| Transformer-XL | shift输出接展开graph外框；child→parent boundary被忽略 | `_rel_shift`最终slice/view结果出线到相对分数消费者 |
| Autoformer | trend与seasonal出口混用，memory只接cross外框 | trend来自moving average；memory进入cross投影的K/V，Q来自decoder |
| PatchTST / iTransformer | scores和统计字段缺少明确接口 | raw scores进入下一层Softmax前的`prev`；反归一化读取保存的mean/std |
| TimeMixer | 返回list只收到最后递推尺度 | 补齐每个保留尺度到collection的真实依赖，并保留trend逆序恢复 |
| Transformer | 外层Attention/FFN/Add & Norm容器被当成计算端点；memory线在cross外框结束 | 展开后接真实投影、Add、LayerNorm、Linear等算子；memory只供WK/WV，WQ读取Decoder状态；位置编码buffer供真实Add |
| 残差mini教学图 | 未画输入x，旁路起点容易被误读为F输出 | 补独立Input x；x分别供F和Add & Norm的skip，不把F.out当作残差输入 |

Model Zoo修订前的234项独立断言有40项不通过；修订后234项通过。模块专题在旧228图中发现110处展开端点接口/续线问题。这些计数是不同审计断言或端点，不能简单相加当成独立源码错误数；旧版几何检查通过也不能抵消它们。

## 接口解析规则

`port_bindings`声明源码字段与内部算子的对应。例如：

```python
# scope.skip 是encoder的返回，不是几何right端口，也不是pool输出。
encoder['port_bindings'] = {
    'skip': {'node': 'unet_enc1_block', 'port': 'out'}
}
# 输出字段不同，不能都递归到stage最后一个算子。
stats['port_bindings'] = {
    'mean': {'node': 'manual_fused_bn.moments', 'port': 'mean'},
    'var': {'node': 'manual_fused_bn.variance', 'port': 'out'},
}
```

普通chain接口沿真实IR boundary继续递归；graph必须有明确接口，不能按rank或图元首末位置猜。折叠容器保留所代表的命名字段；展开后恢复精确可见算子。元组与多个操作数分别布线，非交换操作保留源码顺序。`retained :in`追溯原输入，不下沉到变换后的末端。

渲染从完整IR边清单生成路径，容器接口别名作为解析规则，不再重复画成无续线的外框箭头。每条IR边记录为实际路径、同一可见依赖、接口别名或折叠内部依赖；不得无记录消失。位置、side/.aux槽位与避障都只负责几何，不改变张量身份。

共享绘图器在实际SVG的`data-endpoint-binding`、layout的`port_fields`中保留canonical字段、最终图元与实际端口。时序绘图器使用`data-semantic-trace`。Transformer独立绘图器保留`data-src/dst`、`data-canonical-src/dst`、`data-semantic-edges`，张量网格的value alias绑定真实owner；Q/K/V不能因几何可达而互换。验收器读取实际XML，独立检查图框、路径、箭头方向、字段及源码绑定；tooltip仅用于阅读。

修正前完整文件保存在`before/`，旧迁移核验基线和历史snapshots保持原样。当前图像、语义接口和布局有意更新，不用覆盖旧基线来宣称原图字节保留。[历史Transformer逐图记录](transformer/history_integrity.json)说明旧7图中的匿名端点、PE身份和残差起点局限；它们仅作为历史版本保留，当前使用应选择已修正的正式版或compact版。

本次证明的是固定源码与选定配置下的静态适配合同和导出端点一致；模型语义仍需源码审阅后编写适配器，不证明任意源码自动恢复、未选运行分支或数值等价。内核/库调用中未展开的区域保持明确边界。
