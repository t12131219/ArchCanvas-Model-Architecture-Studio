# Model Zoo实际箭头语义独立审计

范围：25 个模型 × 3 视图，共 75 个 SVG。
核对 1730 个实际图框、1446 条 SVG 路径、1446 条显式类型依赖。

检查固定源码哈希与 AST 符号范围，独立遍历 IR 边界与接口别名，再比较真实 SVG XML 的图框、路径坐标和命名字段。不导入绘图器或其端点解析函数。

## 当前结果

75 个视图全部通过，实际路径端点错误为 0。逐路径记录见 [full_actual_svg_audit.json](full_actual_svg_audit.json)。

JSON 保留每条显式箭头的源码符号/行号、IR 端口、期望可见节点、实际布局端口和 SVG 坐标。
折叠容器可作为不透明摘要；展开容器必须有真实边界续线或显式接口绑定。布局 rank 不能充当数据依赖。
本检查没有执行模型；叶子命名端口的值身份仍依赖可审查的源码适配合同，不能仅由 SVG 像素证明。
