01 / ARROW STYLE

箭头由 Edge Style 绘制

本地 `edge-router.graphml` 的 61 条边都给出 `targetArrow = TRIANGLE`、`sourceArrow = NONE`。在线运行时抓到 61 条 teal 路径和 61 个同色闭合箭头路径；箭头在末端单独绘制。切换箭头不会改变路径坐标。

<yjs:PolylineEdgeStyle orthogonalEditing="true">
  <targetArrow> TRIANGLE · cropLength=1 </targetArrow>
  <sourceArrow> NONE </sourceArrow>
</yjs:PolylineEdgeStyle>

证据：resources/edge-router.graphml:459–472 · LayoutStylesDemo.js:792–827 · runtime/orthogonal-paths.json

02 / PORTS & CONNECTIONS

连接关系由 source/target port 保存

GraphML 边带 `sourceport` / `targetport`，节点声明 `p0…` 命名端口。运行时设置 Allowed Port Sides 后，配置将 EdgePortCandidates 同时写入 source 与 target。端口限制改变“从哪一侧离开/到达”，不移动节点。

layoutData.ports.sourcePortCandidates = candidates
layoutData.ports.targetPortCandidates = candidates

证据：edge-router.graphml:81–92,459–460 · PolylineEdgeRouterConfig.js:624–636 · runtime/general-settings-dom.txt

03 / REROUTING TRIGGER

Showcase 的 Apply 才调用路由器

GraphEditorInputMode 注册创建、删除、复制、标签和 edge-created 事件来标记 Modified Graph。源码没有在节点拖动事件中调用 layout；Apply Layout 与 Ctrl/⌘+Enter 才进入 LayoutConfiguration.apply / LayoutExecutor.start。这和另一个 interactive-edge-routing demo 的拖动后自动重算不同。

拖动节点节点位置变化 · 旧路径留在画布
→
Apply Layout作用域 + 策略 + 端口候选生效
→
新路径节点坐标保持不变

证据：LayoutStylesDemo.js:869–887,914–936,1071–1077,1127–1137 · LayoutConfiguration.js:68–111

04 / ROUTING STYLES

Orthogonal / Octilinear / Curved

Edge Router 将路径风格放进 EdgeRouterEdgeDescriptor：正交是水平/垂直段，Octilinear 增加斜段，Curved 让转弯平滑。在线切换 Curves 后画布保留节点与箭头，路径从长直角折线变成平滑采样曲线。本次对比：16 个节点矩形属性完全一致；61 条边中 45 条路径改变，L 指令从 111 增至 732（最终 SVG 无 C/Q 指令）。

证据：PolylineEdgeRouterConfig.js:511–560,582–599 · runtime/curved-paths.json
