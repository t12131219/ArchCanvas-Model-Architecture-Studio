- heading "Edge Router" [level=2]
- paragraph: Edge routing calculates orthogonal, octilinear or curved edge paths for a diagram's edges. The positions of the nodes are not changed by this algorithm.
- paragraph: By default, edges will be routed orthogonally, that is, each edge path consists of horizontal and vertical segments. The Octilinear style inserts additional sloped segments between horizontal and vertical segments, and the Curved style replaces those segments with smooth curves.
- paragraph: This type of edge routing is especially well suited for technical diagrams.
