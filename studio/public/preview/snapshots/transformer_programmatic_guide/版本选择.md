两个版本使用相同的源码语义与参数身份，区别在于模块内部的展示方向。当前默认仍为统一自底向上版，上次的箭头优化结果另存为完整可选版本。

紧凑版保留两种内部方向选择，已同步本轮源码端点修复；当前 SVG、脚本、布局及检查记录因此不再与最初保存时逐字节相同。原始结果仍原样保存在 `snapshots/before_bottom_up/`，`preservation_manifest.json` 只证明当时保存状态。图3尺寸与约 9.9% 缩高保留。

在本交付目录运行以下任一命令，即可生成对应版本；输出分别写入各自的 `generated/`，互不覆盖：

```bash
# 当前默认：统一自底向上
python3 draw_transformer.py
```

```bash
# 可选：上次的紧凑混合方向版
python3 variants/compact_mixed_flow/draw_transformer.py
```

两份脚本均静态解析源码，不运行模型。当前两版的叶端点、张量别名与完整实际依赖已核验，mini 明确显示 Input x；详见 [本轮专项审查](../arrow_semantic_audit/transformer/README.md)。原始 snapshots 七张 SVG 保持字节不变，其中旧端点缺陷仍存在，不能把历史恢复副本视作本轮验证后的版本。
