# Publication Compiler Rules

- Compile only from `ArchitectureIR`; never inspect or write project source files here.
- A publication reduction must retain an Exact member mapping or an explicit omission ledger.
- Pattern matching is conservative. Unsupported structure stays ungrouped or unresolved upstream.
- Visual expansion belongs to `VisualScene`, not `PublicationIR` or an Exact-node mapping.
- Update publication tests and deterministic golden documents with every intentional output change.
